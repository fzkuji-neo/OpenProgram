数据与失败处理

经过所有者授权的 Memory 端点读取有界 Git 历史，仅限主题 Markdown。在现有写锁下比较提交的基础内容，拒绝过期编辑。由于规范化可能修改源码，返回规范保存文本。仅内联显示错误和 Git 警告，不显示“保存中”或“已保存”。跨导航和刷新保留本地草稿，按文件串行保存。旧响应不得把后续输入标记为已保存。

验收

主题与 Core 默认预览，无保存按钮。输入自动持久化，切换文件后仍保留，并产生可见 Git 记录。撤销按单次编辑回退；历史可恢复选定版本。历史支持更早分页和父版本差异。保存被拒绝或发生冲突时保留草稿并显示错误。路径与版本输入不能逃逸 Memory。现有源码验证与渲染保持不变。

来源链接与侧栏

归档隐藏会话，不按期限或容量删除。原会话已删除时链接不可用，标注“原会话已删除”；不因删除另建来源副本。展示内容前检查现有 Memory 来源存储。Memory 导航和刷新控件复用主侧栏行及图标按钮样式。
