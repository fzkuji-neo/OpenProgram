Entry names and supporting information

Use the actual resource name as the primary title, such as Baidu: search and find out or Ubuntu development environment. Page-title changes update the entry without changing its group.

The subtitle displays states such as Operating, Running or Connection failed and, when needed, the owning Agent. Preserve source, branch and connection information without an extra session-title grouping level.

External is a source, not a separate type. External VMs remain under Virtual machines and external pages under Web pages. Only truly unrecognized objects use Other resources.

Show only resources actually associated with the current session. Display types only when they contain resources, in the fixed order above; Agent switches or renaming do not reorder categories. Counts represent valid resources of that type.

Remove closed or exited resources from the active list; existing history capabilities may expose them through details. Retain resources with uncertain status under their original type and show an error rather than treating them as closed. Persist collapse state by session and type.

Title bar

The page badge associated with the input area shows only the page name, omitting Left / Right / Center position text; hover still explains Agent access.

Resource name + Open icon + More icon + Close preview icon (X). Remove pin and expand/shrink buttons. Retain dragging and edge resizing and compatibility with saved dimensions.

In narrow windows, truncate the title first and retain every action icon. Open uses an outward arrow, More uses dots and Close preview uses X; all have hover hints and accessible names.

More menu

Use the application's own overlay menu. The automatic-display option has an explicit checkbox, wrapping title and separate description below. Keep the description visible rather than putting it in a single-line menu title or tooltip. Desktop uses the existing HTML menu overlay over native pages; Web uses the same content and styling. Display operations use checkboxes; action history retains a submenu. Toggling keeps the menu open and updates checks immediately for consecutive adjustments. Escape, outside click, clicking More again or closing the preview dismisses it. If automatic preview is enabled with no Agent-operated page, retain the current page; automatic page switches also keep the menu open.

Web pages retain Automatically show the page the Agent is operating; action records and display-action markers move to More. VMs, terminals and applications show only actually supported features.

Persist type collapse, resource-panel hiding and preview hiding independently: collapsing a type hides list rows only; hiding the right panel does not automatically hide the preview.

State transitions and boundaries

Resource available, preview hiddenClick entry → Show that resource

Manually selecting a page enters keep-current-page mode. Existing right-hand buttons remain unchanged.

Preview visibleClick Hide → Hide only the view

Retain resource selection and display mode. Later Agent activity must not reopen it automatically.

Follow enabled, preview visibleAgent switches page → Update preview

Select only pages allowed in the current session, without replacing a VM or terminal being viewed.

  • At most one preview per session. Switching resources replaces its view; switching sessions hides the old session's preview and restores the new session's own selection and visibility.
  • When manually viewing a non-page resource, page following must not replace it. Reopening a web page applies the session's saved display policy; explicitly selecting a page keeps that page.
  • Without preview capability, open existing details rather than showing a fake preview or connected state. Unknown capability, connecting and failed connection have explicit states.
  • Resource identity, session ownership and access rights do not change with grouping or view switches. Open for pages still follows existing top-tab discoverability rules.
  • Temporary loading failure retains known types and entries and displays refresh failure. Do not rename, auto-select another resource or retry a close operation with an unknown outcome.
