条目名称与辅助信息

主标题使用真实资源名称，例如“百度一下，你就知道”或“Ubuntu 开发环境”。网页标题变化只更新条目，不改变所在分组。

副标题显示“操作中”“运行中”“连接失败”等状态，必要时显示所属 Agent。保留来源、分支和连接信息，不再增加一层会话标题分组。

“外部”是来源，不单独成为类型。外部虚拟机仍归入虚拟机；外部网页仍归入网页。只有确实无法识别的对象进入“其他资源”。

只显示当前会话真实关联的资源。有资源的类型才显示，使用上述固定顺序；不因 Agent 切换或名称变化调整分类顺序。数量表示该类型的有效资源数。

已关闭或已退出的资源从活动列表移除；如已有历史记录能力，详情入口可查看。状态无法确认的资源保留在原类型下并显示错误，不能当成已关闭。分组折叠状态按会话与类型保存。

标题栏

输入区对应的网页标记只显示网页名称，省略 Left / Right / Center 位置文字，悬停仍说明 Agent 是否可访问。

资源名称 + 打开图标 + 更多图标 + 关闭小窗图标（X）。移除图钉和放大／缩小按钮。沿用拖动与边缘调整大小，已有窗口尺寸继续兼容。

在较窄的窗口中，优先省略标题，保留全部操作图标。打开使用向外箭头，更多使用三点，关闭小窗使用 X；均提供悬停提示和可访问名称。

更多菜单

使用应用自己的浮层菜单。自动显示选项由明确的复选框、可换行标题和下方独立说明组成；说明保持可见，不放入单行菜单标题或悬停提示。桌面端使用现有 HTML 菜单浮层覆盖原生网页；网页端使用同样的内容与样式。显示操作使用复选框，操作历史保留子菜单。勾选或取消勾选时菜单保持打开，勾选状态即时更新，便于连续调整。按 Escape、点击外部、再次点击更多或关闭小窗时关闭菜单。开启自动预览但暂时没有 Agent 正在操作的网页时，保留当前网页；自动切换网页也不关闭菜单。

网页保留“自动显示 Agent 正在操作的网页”，操作记录和显示操作标记进入更多菜单。虚拟机、终端、应用只显示其实际支持的功能。

分组折叠、资源面板收起和小窗收起分别保存：折叠类型只隐藏列表行；收起右侧面板不自动收起小窗。

状态变化与边界

资源可用、小窗隐藏点击条目 → 显示该资源

手动选择网页进入保持当前网页模式。右侧原有按钮保持不变。

小窗显示中点击收起 → 仅隐藏视图

保留选中资源与显示模式。后续 Agent 操作不能自行重新弹出。

跟随已开启、小窗可见Agent 换网页 → 更新预览

仅选择当前会话允许显示的网页，不切走正在查看的虚拟机或终端。

  • 每个会话最多显示一个小窗。切换资源替换视图；切换会话隐藏原会话的小窗，恢复新会话自己的选择和可见状态。
  • 手动查看非网页资源时，网页跟随不得替换当前视图。重新打开网页后再按该会话保存的网页显示策略处理；显式选择某网页则保持该网页。
  • 没有可预览能力时打开现有详情视图，不能显示假的预览或“连接成功”。能力未知、连接中、连接失败均有明确状态。
  • 资源身份、会话归属和访问权限不因分类或视图切换变化。网页“打开”仍遵守现有顶部标签可发现性规则。
  • 数据暂时加载失败时保留已知类型与条目，显示刷新失败；不改名、不自动选其他资源，也不重试未知结果的关闭操作。

实施顺序与验收

步骤改动位置验收条件
1. 类型分组groupSessionResources 与资源面板标题映射网页和虚拟机分别成组；重命名会话或网页不改变分组；同类型跨分支资源仍属于同一类型组
2. 收起与菜单WebTabPip、小窗菜单与双语文案；右侧条目按钮保持现状小窗 X 可隐藏视图；右侧预览按钮可重新打开；右侧按钮行为不变；无图钉和放大按钮；菜单跟随语义一致
3. 不同资源呈现已有 Terminal / Application 视图与各提供方能力共用显示与收起含义；不新增 VM 控制后端；无预览能力显示详情
4. 状态与安装验证现有资源 store、会话选择与持久状态跨会话隔离、隐藏后不自动弹出、刷新恢复、最窄窗口不遮挡收起按钮

先确定本页交互，再修改生产代码、更新现有正式设计、执行独立审查与测试，最后验证默认 App。实施完成后更新默认 App，并验证真实的资源按钮与小窗。

桌面菜单由已有原生菜单服务处理。主进程 IPC 与控制浮层共用同一个服务实例；模块导出与调用方引用必须一致。验收包含授权窗口弹出菜单、选择返回及取消清理。
