边界

服务器在返回资源前检查会话和执行授权。浏览器行仍由渲染进程管理；后端行请求仅涵盖所选会话。通过获授权后代范围返回的行仍按实际会话所有者过滤。记录载荷只包含长度受限的显示字段；URL 省略凭证、查询参数和片段。资源面板参与现有右侧面板布局。原生浏览器边界随剩余中央区域调整，使资源和网页同时可见。

用户提供的 Chrome 参考用于设计可搜索、按组显示的资源行。已批准的位置是右侧可折叠面板。实现复用现有右侧面板、中央标签存储、获授权资源路由和原生浏览器边界上报，不引入第二套浏览器管理器或通用破坏性操作协议。

会话预览与 Page 访问

预览独立于可复用聊天标签 ID 保存会话 ID。在聊天标签内或通过其历史导航时，只显示所选会话的预览。未选择 Page 的会话不显示预览；返回时恢复该会话自己的选择。隐藏预览不会释放或公开 Page。

尚未作为顶层标签打开的保留 Agent Page 只属于其记录的会话。Page 清单、轮次上下文、截图、解析、激活和关闭均通过可信执行会话归属强制检查所有权，独立于当前 UI 标签。显式“打开页面”将已有 Page 暴露为常规标签：其他会话可以发现它，但只有现有独占 Page 租约允许时才能取得控制。公开 Page 改变可发现性，不改变原始来源或预览归属。关闭标签会移除其预览。异步结果交付前仍必须匹配当前访问范围。

这扩展了现有渲染进程管理的标签来源和服务器管理的 Page 租约，不引入替代浏览器记录表。现有 GUI Agent 预览和内置浏览器文档仍为权威依据。验收涵盖同标签会话导航及前进/后退、独立聊天标签、私有页面发现和精确 ID 拒绝、显式公开打开、忙碌 Page 拒绝及释放后取得控制，以及原生操作等待期间的访问变化。

统一资源接口

资源用于标识持久环境。终端资源是现有 PTY 和 shell，而不是命令记录。网页、终端和已安装应用共享发现、身份、会话归属、能力描述及视图选择。现有提供方保留执行权限和类型特定操作 schema。

共同操作网页终端应用
list / describe获授权 Page 清单及支持的操作原生宿主清单及 generation已安装、已启用应用的 manifest 和声明操作
open显式创建 Page显式创建私有 shell打开已安装应用实例
observe具有当前身份的 Page 观察独立输出游标和输入修订号实例状态和操作状态
act现有 web_use 操作携带已观察修订号的输入或中断仅限声明为 Agent 可见的操作
release释放控制绑定释放 Agent 绑定，保留进程解除资源关联；操作保留各自明确的生命周期
close在支持时显式关闭 Page请求终止进程；等待实际退出仅在应用声明支持时可用

不支持的操作返回明确的能力错误。共同接口不会为提供方虚构关闭、暂停、截图或键盘支持。结构化观察保留图像、输出游标和类型化结果。现有 web_use 与 terminal_use 保持为兼容的公开入口。资源标识符不等于访问授权。

共享交互
