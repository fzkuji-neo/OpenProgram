侧栏会话状态

运行中且未等待用户输入的会话显示三个脉动圆点，置顶会话也相同。只有选中的运行中会话行显示背景扫描动画。选中状态由 aria-current="true".

渲染

ConvItem 按 needs-input、running、unread 的优先级选择状态。StatusMarker 优先显示该状态，再考虑置顶和空闲标记。等待输入时保留琥珀色标记。CSS 隐藏未选中行的 running 和 finishing 伪元素。后端状态、任务执行、导航和会话持久化保持不变。

安装与恢复

TSX 和 CSS 源码通过常规发布资源流程构建。已提交的 checkout 通过 scripts/refresh-local-app.sh 安装，同时替换默认 App 的 runtime 与前端。禁止手工修改已安装的压缩 JavaScript 或生成资源名称。工作区根 package manifest 保留 workspace 定义，与桌面端 package manifest 分开维护。
