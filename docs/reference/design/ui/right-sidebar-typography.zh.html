右侧边栏文字排版

Files、Activity、Resources、执行详情和上下文记录共用应用现有字号。导航、分组标题、条目名称和普通详情正文使用 --fs-base（14px）、常规字重和 20px 行距。状态、数量、时间、路径、文件大小及辅助说明使用 --fs-sm（13px），保持相同行距。代码、标识符和终端输出保留等宽字体。虚拟文件树保留原有 30px 行高。

安装界面原先混用 10–14px：Activity 名称为 13px，资源名称为 12px／500 字重，资源说明为 11px，文件树还采用独立字体。右栏作用域内的共享变量统一同类文字，复用组件在其他位置保留原有回退样式。不改变资源归属、执行状态、导航、文件树虚拟化或持久化设置。

实现与边界

复用现有字号和字体变量、SectionHeader 与文件树主题接口，统一资源列表和运行记录的行内边距及主副文字间距。不添加全局元素重置或新的排版组件，不强制大写，不改变文档和终端内容。

验收

在默认安装版 App 中检查有内容的 Files、Activity 和 Resources，再检查执行详情和上下文记录。核对计算样式和实际显示，确认主副文字分别一致，窄栏和宽栏没有控件截断或新增横向溢出，选择、折叠和键盘焦点保持可用。文件树同时检查 shadow root。执行 Web 检查、Web 测试、TypeScript、仓库契约和文档链接检查。

实现状态

源码已采用共享右栏文字样式，覆盖文件树主题及执行、上下文元信息。独立规格与质量审查、完整检查和安装版 App 验收仍是必需的发布检查。保留既有 Goal 和固定预览视口行为。
