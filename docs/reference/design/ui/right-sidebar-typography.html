Right sidebar typography

Files, Activity, Resources, execution details and context records share the application typography scale. Navigation, section labels, item names and ordinary detail text use --fs-base (14px), regular weight and a 20px text line. Status, counts, timestamps, paths, file sizes and helper text use --fs-sm (13px) with the same line rhythm. Code, identifiers and terminal output retain their monospace face. Virtualized file rows keep their existing 30px geometry.

The installed interface previously mixes 10–14px text: Activity names use 13px, resource names use 12px/500, resource metadata uses 11px, and file rows use a separate tree font. Shared scope variables on the right sidebar make role-equivalent labels consistent. Components used elsewhere keep their current fallback styles. No resource ownership, execution state, navigation, tree virtualization or persisted settings change.

Implementation and boundaries

Reuse the existing application font and size tokens, the shared SectionHeader and native tree theme overrides. Match resource and Activity list padding and title/metadata spacing. Avoid global element resets, a new typography component, forced capitalization and changes to document or terminal content.

Acceptance

Inspect computed styles and visible rendering in the installed default App for populated Files, Activity and Resources, then inspect an execution detail and context records. Confirm matching primary and secondary roles, no clipped controls or new horizontal overflow at narrow and wide sidebar sizes, and preserved selection, disclosure and keyboard focus. Check the file tree shadow root as well as ordinary DOM. Run Web checks, Web tests, TypeScript, repository contracts and documentation links.

Implementation status

The source uses the shared sidebar text roles, including file-tree theme overrides and execution/context metadata. Independent specification and quality reviews, the full verification commands and installed-App acceptance remain required release gates. Goal and fixed-preview behavior are retained.
