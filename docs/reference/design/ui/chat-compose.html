Chat quotes and message editing

Select text in a message to reveal an Add to chat button above the selection. The selection button uses a compact 32 px height, 8 px corner radius, a subtle border and shadow, and an opaque theme-aware popover background. Hover and pressed states mix solid theme colors, never replace the background with a translucent overlay. Keyboard focus has a visible outline. The message action row also quotes a whole message. Quotes append Markdown blockquotes to that conversation's draft and focus its composer. Existing drafts and attachments remain intact; sending is explicit.

Historical user messages open an inline composer with the same text field, file mention picker, attachment processing and preview strip as the bottom composer. Existing attachments can be removed; images and documents can be picked, pasted or dropped. URLs remain editable text. Cancel discards only the edit. Save and resend creates a sibling branch through the existing edit route. Errors retain the edit and show a retryable message.

References: the user-supplied Codex selection screenshot establishes the selection action; no external product parity is claimed. Side chats and extra selection actions are outside this change.

Implementation and acceptance

Per-pane session ownership is explicit. Uploaded bytes use the existing bounded attachment persistence and image dispatch path. Retained image copies are read through the authorized raw-file API; retained legacy attachment blocks stay lossless. No automatic submission and no new permission modes.

Gate: focused browser interaction tests for quote draft preservation and split ownership, inline attachment editing and failure retention; REST edit attachment validation and dispatch tests; TypeScript check; documentation links; production build during the standard local refresh. Independent specification and quality review precede integration.
