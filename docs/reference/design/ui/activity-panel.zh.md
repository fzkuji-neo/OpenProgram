# Activity 面板

右侧栏的 **Activity** 列出一个会话的 agent 分支：最上面是主代理，下面是它启动的子代理，排成一棵树。要你处理的事列在它们上面，后台程序列在下面。消息从不成行，留在聊天里。

## 分支、运行与待处理事项

**子代理**是显示类型为 `job_agent` 的执行。每个执行都属于一条**分支**：子代理负责它自己，以及它下面没有被更深一层子代理接管的执行；其余都属于**主代理**。子代理挂在它上方最近的那个子代理下面，没有的话就挂在主代理下面。

底层的执行组成**运行**：一个顶层执行，通常是一条消息加上为它做的所有事。子执行、尚未返回的函数调用和托管程序归属于包含它们的运行。运行有自己的页面（从主代理的“最近一次运行”、子代理的“来自”或停在问题上的消息进入），但不单独成行。

已返回的 `agent` 调用会和它启动的子代理配对。服务端从对话记录里读取这些调用：Job 记录了派生它的回复（`spawn_caller`）和它的提示词，调用方相同、提示词相同的那次调用就是启动它的调用；没有失败的调用先配对，因为失败的调用可能和重试用了同样的提示词。提示词对不上时，如果一个调用方只剩一个 Job 和一次没有失败的调用，就把它们配成一对。没有配到 Job 的调用就是**没有启动成功**（结果是 `[agent error] …` 或 outcome 为 `failed`）或没有启动。记录行的 caller 说明是哪条分支发起的调用：`j_…` 开头的回复属于子代理，其余属于主代理。这里不读 effects：它们的元数据里带着完整的模型请求，读起来太慢。

**待处理事项**是具体在等你的事：

- 已停止的调用：运行在它返回前停止；
- 停在问题或审批上的执行，或者在一个操作途中停止、且没有被某个已停止调用说明的执行；
- 状态未知或丢失的程序。

只缺模型响应记录（`provider_response_incomplete`）的执行不算待处理，显示为已结束。

## 总览

三组，顺序固定；空的组不显示，所有组都不能折叠。

1. **要你处理**：待处理事项，从新到旧。行就是这件事本身（“Fix page close · 子代理已停止”），不是整段会话。子代理已列出的已停止 `agent` 调用，以该子代理的身份显示。
2. **Agent 分支**：先是主代理（会话自己的 agent，命名和图标与子代理一致），然后是它下面的所有子代理，深度优先、从新到旧。每个子代理缩进挂在启动它的分支下面：一条细折线从那个分支的图标下方连到它自己的图标，线继续延伸到它后面的兄弟行；上方还有后续兄弟行的分支，它们的线也会穿过这一行。主代理显示为正在运行（写出当前调用或“等待子代理”，以及已用时间）、在等你（暂停中，或有它自己的待处理事项）、上次运行后空闲，或上次运行失败。子代理显示为正在运行及当前调用、已停止，或最终状态加时间。没有建出子代理的 `agent` 调用放在树里那个子代理本该在的位置，显示为“没有启动成功”或“没有启动”。树每次显示 20 行，点“显示更早”继续。执行不在列表里的调用和程序算作主代理的。
3. **后台程序**：所有程序，正在运行的排前面，其余从新到旧，每次 20 个。

调用和程序在执行列表读取之后才归位，不会先闪现为无归属。

## 页面

每一行点进去都是一个页面；面板背后是一个页面栈，返回箭头写出要回到的页面。任何地方都不原地展开。

- **主代理**：会话标题和状态。先列它自己的待处理事项，然后是正在做的事、“最近一次运行”和“它启动的子代理”，包括没有启动成功的调用。“技术详情”打开最近一次运行。
- **子代理 / 运行**：类型、开始时间和用时、名称或消息、状态。待处理事项排在最前，操作用浮起的胶囊按钮：执行允许时“标为已结束”（取消），暂停时“去处理”/“查看详情”。子代理另有“打开它的对话”、“由谁启动”（主代理或上方的子代理）、“来自”（启动它的那条消息对应的运行），以及取自 `agent` 调用的“交给它的任务”。然后是它做了什么：未返回的调用（`agent` 调用通过它启动的子代理进入）、子执行、它启动的子代理和没有启动成功的调用、程序。“技术详情”打开执行检查器，只有它会读取事件和调试数据。
- **没有启动成功**：调用的说明、发起时间和“没有启动成功”，一句说明它没有自己的对话，然后是“由谁启动”、报错那一行和任务。
- **调用**：以说明为标题，显示类型、开始时间、状态、来自哪次运行，以及任务（`prompt`）或命令。任务按正文显示，命令用等宽字体；都先显示几行，点“展开全文”看全部。
- **程序**：状态、来自哪次运行、工作目录、运行环境、退出情况、命令和输出，运行中可以“停止程序”。

## 外观

行在静止时没有框：裸露的类型图标用该类型的颜色，名称下面是以共享状态圆点开头的状态行，右侧一个箭头。悬停时整行浮起成文件卡片那种卡片。页面上的待处理事项用浅琥珀色底，没有边框。
