# Activity 面板

右侧栏的 **Activity** 针对一个会话回答三个问题：有什么要你处理、现在在跑什么、之前跑过什么。

相关：[`indicator-dots.md`](indicator-dots.zh.md)（状态圆点），
[`sub-agents-card.md`](sub-agents-card.zh.md)（子代理自己的对话）。
代码：`apps/web/components/right-sidebar/running-panel.tsx`、
`apps/web/lib/execution/activity-model.ts`、
`openprogram/execution/activity_calls.py`。

## 单位是一次运行

每一行是一次**运行**：一个顶层执行，通常就是一条消息加上助手为它做的所有事，标题就是那条消息。子执行（子代理、派生分支）、尚未返回的函数调用和托管程序，归属于包含它们的那次运行。会话分支不是面板的一层。

**待处理事项**是具体在等你的事：

- 结果待确认的调用：运行在它发出后中断；
- 停在问题或审批上的执行，或者持有一个待确认操作、且没有被某个待确认调用说明的执行；
- 状态未知或丢失的程序。

只缺模型响应记录（`provider_response_incomplete`）的执行不算待处理，显示为已结束。

## 总览

三组，顺序固定；空的组不显示，所有组都不能折叠。

1. **要你处理**：待处理事项，从新到旧。行就是这件事本身（“Fix page close · 子代理结果待确认”），不是整段会话。
2. **正在运行**：进行中的运行，写出当前调用和已用时间；所属执行不在列表中的调用和程序也放在这里。
3. **记录**：已结束的运行，从新到旧，按天分组，每次 20 条，点“显示更早”继续。

调用和程序在执行列表读取之后才归位，不会先闪现为无归属。

## 页面

每一行点进去都是一个页面；面板背后是一个页面栈，返回箭头写出要回到的页面。任何地方都不原地展开。

- **运行**：类型、开始时间和用时、标题、状态。待处理事项排在最前，操作用浮起的胶囊按钮：执行允许时“结束这次运行”（取消），暂停时“去处理”/“查看详情”，子代理“打开它的对话”。然后是“这次运行做了什么”：未返回的调用、子执行、程序。由 `agent` 调用启动的子代理通过那次调用进入，不重复列出。“技术详情”打开执行检查器，只有它会读取事件和调试数据。
- **调用**：以说明为标题，显示类型、开始时间、状态、来自哪次运行，以及任务（`prompt`）或命令。任务按正文显示，命令用等宽字体；都先显示几行，点“展开全文”看全部。
- **程序**：状态、来自哪次运行、工作目录、运行环境、退出情况、命令和输出，运行中可以“停止程序”。

## 外观

行在静止时没有框：裸露的类型图标用该类型的颜色，名称下面是以共享状态圆点开头的状态行，右侧一个箭头。悬停时整行浮起成文件卡片那种卡片。页面上的待处理事项用浅琥珀色底，没有边框。
