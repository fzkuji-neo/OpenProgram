行为约定

  • 将现有思考面板右上角的问号按钮替换为 GaugeIcon 按钮。保留强度标题和滑块的位置。React 实现使用用户提供的 GaugeIcon 路径及弹簧动画（stiffness 160、damping 17、mass 1）。指针静止表示关闭；Fast 开启时持续显示前移的指针。图标保持描边。启用 Fast 时仪表采用主题危险色，关闭时恢复继承的弱化颜色。启用不会增加边框、发光或火焰效果。仅键盘聚焦时显示焦点环，独立于选中状态。悬停时指针运动，并为 24px 点击区域着色；键盘聚焦时展示状态和供应商专属使用说明。移除重复的 Fast 菜单项，不添加独立速度标签。收起的强度控件只显示强度标签。Fast 位于展开的面板内。不照搬参考截图中的固定加速倍数。
  • 默认使用 Standard。按会话和路径/模型身份保存选择。未使用过的路径从 Standard 开始；切换模型不得静默启用付费档位。仅为原先已支持的路径恢复已有会话偏好。
  • 未经验证的路径保留可见、可聚焦但不可用的控件，并说明原因。不得将其描述为模型确定不支持 Fast。明确不支持与未知是不同的能力状态。
  • 速度更改作用于下一次提交的轮次。排队消息保留提交时的设置；正在运行的请求不受影响。Fast 不改变 Xhigh 或其他思考设置。
  • Standard 显式覆盖 agent 的 priority 默认值。不能仅以省略字段表示“关闭”，因为当前循环可能继承该默认值。

实现顺序与验收

  1. 能力解析：agent 设置将受支持的 xAI API 和 Grok 4.6 订阅与未知订阅模型分开。切换路径更新可见原因。显式 false 优先。目录失败时保留已知支持。
  2. 输入框：键盘和指针均可选择速度；重新加载会话后保留选择；切换到其他模型时从 Standard 开始；窄屏布局仍可使用。不出现重复开关。启用仪表时面板保持打开，滑块不移动。收起的强度控件不显示 Fast 图形。没有强度滑块的模型保留相同设置弹层和速度控件，省略滑块。打开面板时隐藏“跳到最新”标签，避免两者叠加。
  3. 分发：公开消息提交仅为所选受支持路径生成 priority。Standard 覆盖 agent 的 priority 默认值。排队轮次的设置保持不变。推理参数不变。
  4. 响应证据：合成 priority、default、缺失档位、错误及取消响应均保持准确状态，不重复请求、不虚构价格。付费在线验证需要选定账户并限制请求范围。

实现涉及现有模型列表解析器、供应商元数据、会话设置、输入框控件和提交路径、分发器回退及响应用量投影。用相同行为更新现有 Fast 产品文档。先执行受影响的后端和输入框检查、文档链接检查，再在发布前完成仓库实现审查与全量验证门禁。
