Built-in browser Home button

Add a Home entry to the OpenProgram built-in browser toolbar, reusing the existing new-tab page without introducing a configurable home URL.

Behavior

  • Both the desktop native WebContentsView toolbar and the ordinary browser iframe toolbar display a House icon button.
  • The button title and accessible name follow the current language: Home or Home.
  • Clicking replaces the current web tab in place with the existing ntp page; it does not add a tab or navigate to an external URL.
  • Preserve tab order, active state and compound-tab member position; remove the old web tab id and clear legacy split state that references it.

Boundaries

Do not add custom home settings, search-engine settings, dependencies, background processes or a new page implementation. Back, forward, address input, reload, bookmarks, split view and external opening remain unchanged.
