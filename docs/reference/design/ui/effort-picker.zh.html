思考力度设置

设计与参考

参照本机 Claude 2.31226.0 的实际布局和时序，采用中性刻度轨道、白色滑块、方向性文字过渡和最高档的紫色方格动画。实现独立编写；保留供应商真实档位，不新增 Ultracode 工作流。

行为与动画

选项和推荐标记来自当前模型。多个选项中的最高档触发效果，包括 xhigh、max 或 high。普通档位为灰色轨道；拖动滑块放大 12%，文字在 200ms 内位移并消除模糊。最高档以约 4px 间距排列 3px 圆角方格，从右侧随机反复扩散，700ms 进入，850ms 退出。独立 Canvas2D 实现替换旧 SVG 和全局动画循环。Fast、帮助和参数保存逻辑保持原有行为。

生命周期与验收

关闭、卸载、页面隐藏和减少动态效果时停止动画。减少动态效果保留静态紫色提示。主题颜色使用 CSS 变量，画布不可用时仍可操作滑块。验证键盘、指针、最高档持续动画、退出衰减、模型切换、Fast 独立性以及浅深色和窄布局，并另行验收默认安装 App。函数调用、对话生成和权限均不在范围内。
