# 输入框区域的悬停提示

输入框区域的每个控件（输入框上方的环境条、下方的控制行）悬停时都用同一种提示——`components/ui/tooltip.tsx` 的 `HoverTip`，不用浏览器原生的 `title` 气泡。提示内容是 `TipBody`：

- **标题行**：控件是什么 + 当前值，例如"项目：fzkuji.github.io"、"权限：Auto mode"、"思考力度：Medium"、"对话 Agent：deepseek-flash"。
- **细节行**（浅色，可选）：chip 上放不下的具体信息，比如完整路径、完整分支名和改动数，或者点击会做什么（"点击关闭。"）。

指针停留 1.5 秒后提示才出现；控件自己的菜单打开时不出现；最宽 320px，路径可在任意处换行。

| 控件 | 标题 | 细节 |
|---|---|---|
| 渠道（Local） | 渠道：<名称> | 会话在哪里运行；点击切换 |
| 项目半边 | 项目：<名称> | 目录路径；本会话已固定，或点击选择 |
| 工作目录半边 | 工作目录：<名称> | 完整路径；agent 可读写 |
| 工作目录的 ✕ | 从本会话移除 | 磁盘文件不受影响 |
| Git 半边 | <仓库> · <完整分支> | 未提交文件和 +/−；worktree 路径；菜单能做什么 |
| 添加目录 | 添加工作目录 | 让 agent 在另一个目录里工作 |
| 网页 chip | 网页：<标题> | agent 能否使用；点击切换 |
| 网页预览 chip | 显示网页预览 | 以浮动预览重新显示网页 |
| Goal chip | 目标 | 目标原文；点击查看进度与控制 |
| 权限徽章 | 权限：<模式> | 该模式的说明 |
| 选项（+） | 选项 | 添加文件，开关工具 / 网页搜索 / 沙箱 |
| 工具 chip | 工具 / 网页搜索 / 沙箱 / 无人值守已开启 | 作用；点击关闭 |
| 思考力度 | 思考力度：<档位> | 模型思考多久；点击调整 |
| 模型徽章 | 对话 Agent / 执行 Agent：<模型> | 职责；点击更换模型 |

## 网页预览标题栏

聊天上方的网页预览小窗（`components/center-tabs/web-tab-pip.tsx`）标题栏按钮用同一套 `HoverTip` + `TipBody`。四边四角的八个调整大小把手保留 `aria-label`，但不再冒提示：指针扫过边缘时在网页上方弹气泡只是干扰。标题和状态文字是标签不是控件，保留原生 `title` 以便截断时看到全文。

| 控件 | 标题 | 细节 |
|---|---|---|
| 打开页面 | 打开页面 | 在中间区域切换到这个标签 |
| 查看请求（Agent 等待确认时） | 查看请求 | Agent 正在等待你的确认 |
| 更多（⋮） | 更多 | 自动跟随、操作标记与操作历史 |
| 关闭（✕） | 关闭小窗 | 只隐藏小窗；Agent 继续工作 |
