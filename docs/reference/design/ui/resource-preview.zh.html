资源与操作预览

右侧栏 Resources 列表、聊天预览以及人类接管 Agent 正在操作的 Page 的行为。

English edition

相关：会话资源、浏览器控制界面、Agent 控制提示层。

Resources 与统一操作预览

Resources 按会话分支整理保留的目标。Resources 没有搜索框。单击条目显示可交互聊天预览，并保持现有选择行为。显式“在会话中预览”图标按钮对确切的现有 Page 做同样的事，不增加顶部标签，恢复已隐藏的 PiP；若当前正在查看网页，则回到所属会话，使聊天预览可见。隐藏保留 Page。没有单独的“显示预览”控件。显式“打开页面”把同一 Page 显示为普通顶部标签，并隐藏该预览及其预留空间；返回会话后，除非用户已隐藏，否则恢复预览。网页标签与其 PiP 不得同时显示。桌面 PiP 直接呈现同一个原生 Page，支持点击、输入和拖动时持续更新；窗口大小决定可见区域与页面缩放。从未显示过的 Page 初始使用 1920×1080 CSS 像素视口。普通浏览器使用独立的 sandboxed iframe，受网站嵌入限制，且不共享 Desktop Page 状态。浏览器交互是首项实现范围；原生软件与 VM 适配、轨迹复盘与学习分别讨论后再实施。验证情况与剩余工作集中记录在实现状态附录。

每个会话的右侧 Resources 按分支显示全部已关联的操作目标。Agent 打开的网页默认在后台保留，不增加顶部标签；聊天中只有一个预览，默认显示当前分支最近正在操作的目标。浏览器页面、单个应用窗口、宿主桌面与 VM 虚拟屏幕使用同一套选择规则，实际输入能力分别校验。

函数结果用 target（window_id、pid、app_name）写明它操作的窗口时，预览切到该应用。worker 每个会话只在内存里保留最新窗口和它最后一张截图，以 native.window 事件通知 App，画面由 /api/session/{id}/native-window/frame 提供；agentic 子进程里的 GUI 步骤把窗口交给 worker，由 worker 归到拥有该子进程的会话。预览显示 Agent 最后看到的画面，不是实时画面。会话正在使用的终端开始运行或收到新输入时，预览切到该终端，并只读镜像其屏幕。固定只保留 Page；应用和终端目标只跟随，不作为固定保存。

预览标题栏标明自动预览或固定预览，并显示当前控制状态。固定预览保持当前 Page。取消固定预览后恢复自动显示 Agent 正在操作的页面。预览标题变化不会改写 Agent 目标、恢复或启动 Agent，也不改变 Page 生命周期或顶部标签。该固定控件只在聊天预览上，Resources 没有固定按钮。默认 App 验收是单独的发布检查。

资源与预览的职责

  • 持续保留的浏览器资源描述和分支关联组成资源清单。临时使用记录表达执行期间的占用，不决定 Page 的存续。同一个 Page 可以被多个分支引用。
  • 单击资源条目选择可交互聊天预览，并保持当前标签。显式“在会话中预览”使用确切的现有 Page，不固定也不复制顶部标签。单击资源和“在会话中预览”都不改变自动或固定预览；自动预览时 Agent 下一次读取或操作其他 Page 会切换过去，读取（observe）也算一次操作。固定只在本次加载期间有效，不写入存储。若网页占据中心区域，该动作激活所属当前会话，使请求的预览可见，且不改变正在查看的分支。显式“打开页面”把确切的现有 Page 显示为普通顶部视图，并隐藏该预览及其预留空间。跟随不抢占标签焦点。返回会话后，除非用户已隐藏，否则恢复预览。
  • 资源存续、预览偏好和执行输入租约分别记录。窗口级状态更新在 Resources 收起时继续维护自动跟随和控制状态。隐藏预览结束截图订阅并保留目标。

列表与小窗的具体样式

右侧栏顶部的 Files、Activity、Resources 保持现有纵向排列，不改为横向标签。本方案只设计 Resources 内部内容。沿用右侧栏的暗色背景、系统字体和 16px 类型图标；不为每个资源画边框卡片。分组标题复用左侧栏 Pinned/Projects 的 SectionHeader：14px 常规字重的次要色文字，16px 折叠箭头紧挨截断后的分支名，内边距和悬停与左侧栏相同，Current 与数量作为行尾操作。Enter 或 Space 只展开或折叠该组。条目约 44–48px 高，第一行是页面或窗口标题，第二行是类型、状态及需要时的子 Agent 名。标题过长省略，完整标题、脱敏来源和目标身份在详情中查看。悬停使用轻底色，选中使用稍深底色；“正在操作”圆点与“正在预览”选中态分别显示，不只靠颜色区分状态。网页行在标题旁提供三个紧凑 Lucide 图标按钮：在会话中预览、在标签中打开、关闭网页。它们与 PiP 顶栏共用现有紧凑工具栏样式（24px 点击区域、14px 图标，以及相同的悬停、禁用和键盘焦点处理）。不要使用字面箭头，也不要把全局 36px Button 用在这些控件上。

聊天预览标明标题。控件只有一行且不得换行，在最小 240px、默认 300×198.75（300×168.75 画面加单行标题栏）和展开 720px 宽度下均如此：省略标题、紧凑控制状态、打开页面、按状态显示的暂停 Agent，我来操作、让 Agent 继续或重试暂停、始终显示的固定预览 / 取消固定预览、展开或收起、更多、隐藏。标题在按钮之前截断。“显示操作”和“操作记录”放入现有原生安全的更多菜单。主操作留在这一行，不放到第二行或弹出工具栏。截图以未变形的 contain 填满剩余区域并保持截取画面的宽高比，桌面端按窗口宽度调整原生布局缩放，直接接收页面输入。空闲和已关闭显示“可直接操作”，不提供暂停或继续按钮。失败信息通过状态指示、标题提示和 aria-live 可发现，不另加第二行。侧栏宽度复用现有可调整宽度，不固定重做布局；窄屏以 Resources 抽屉选择目标，聊天和预览保持可用。上方样式稿在窄屏改为上下排列以便审阅，不代表新增产品页。

选择与跟随

  • 每个 App 窗口最多显示一个预览，状态按当前会话和分支记忆。自动跟随只响应当前查看分支中，已获宿主许可的实际操作事件；资源刚打开、状态轮询或截图更新本身不切换预览。
  • 多个子 Agent 并行时，按宿主事件顺序跟随最后实际操作的目标，显示正在使用它的 Agent。约 200ms 合并连续更新，只渲染最新帧，不积压旧帧；这是待测初始参数。
  • 点任意资源进入“固定预览”，Agent 继续原任务，预览不会被后台切换覆盖。查看其他分支的资源不切换会话分支，也不授予写权限。按钮明确显示“取消固定预览”以返回自动模式。
  • 隐藏小窗只改变可见性；后台操作继续，Resources 保留全部目标。后续事件不自动重新弹出，点条目或“在会话中预览”才恢复。隐藏保留 Page。手动展开只改变展示尺寸，不复制 Page 或把应用置前。
  • 切换分支后恢复该分支的预览偏好；从未选择时跟随其最近操作目标；该目标已关闭则显示不可用，没有操作记录时显示空状态。其他分支仍可运行，其消息不能覆盖当前预览。

保留、打开与关闭

  • Resources 不提供 pin 控件，也没有搜索框。单击条目选择可交互聊天预览；“在会话中预览”是可访问的显式等价操作，恢复已隐藏的 PiP，并在网页占据中心时回到所属会话。“展开”显示同一目标的大视图。显式“打开页面”把这个确切的现有 Page 显示为普通顶部标签并隐藏预览。重复打开复用同一 Page。后台 Agent 页面继续保留在 Resources 中。
  • 已有用户手动固定或打开的顶部页面保留为普通用户视图；迁移不能关闭它们，也不自动把所有旧页面隐藏。后台资源不会因为最近使用而自动生成新标签。
  • 任务结束释放 Python、输入租约与临时观察文件，已关联页面和 VM 保留，转为闲置。仅声明为临时的测试/中间资源按原有明确策略销毁，不把“任务结束”当成“关闭所有资源”。
  • 行菜单使用具体动作：“关闭网页”“断开窗口关联”“断开 VM 连接”。“停止 VM”单独列出，不能随关小窗触发；借用的用户 App 不自动退出。
  • 关闭正在使用或被其他分支引用的目标，需要展示受影响执行，先请求停止并等待写租约释放。未能确认停止时保持“停止中”，不能谎报已关闭。已关闭记录移入可折叠的不可用分组；默认数量只计当前可连接目标。

浏览器、软件窗口、桌面与 VM 的能力边界

资源后台目标与预览不可行时如何显示
浏览器 Page复用准确 Page/CDP target；后台保持文档、登录和导航状态。用户看预览不需要激活网页。Agent 网页打开的弹窗在后台加载，按 opener 的会话、分支和执行登记为新资源（webtab_popup），并在 opener 下一次 observe/act 结果里以 opened_pages 告知一次；Agent 经 list_pages 进入弹窗。确实操作弹窗时才跟随。用户网页的弹窗照常在前台打开，不登记。桌面端用 Chromium 为弹窗创建的 WebContents 建立 Page，window.opener 照常可用；渲染端按这个 id 接管该 Page。页面已关闭、脱离归属或 frame 过期时停止写入。重新打开 URL 创建新的资源身份，不冒充原页面状态。
单个原生应用窗口绑定进程实例和准确窗口，可支持窗口截图与经过验证的后台输入。列表显示“后台可操作”“仅预览”或“需要前台”，按动作能力判断。不能承诺所有软件都支持完整后台点击/输入。现有原生矩阵仍失败。最小化、锁屏、权限不足、无法准确定位时给出具体原因；只有用户明确选择前台方式才允许激活窗口。
宿主桌面屏幕对应宿主显示器及其坐标空间，能反映整个桌面。它没有独立于用户的输入环境。全局鼠标和键盘可能影响用户当前工作，不标为“独立后台”。需要协商使用前台，或改用隔离 VM；选中预览不代表允许全局输入。
VM 虚拟屏幕VM 在后台运行，其 guest 虚拟显示和输入适配器提供截图、键盘和鼠标；不要求宿主 VM 控制台保持前台。VM 进程、guest 图形会话与远程显示服务仍须运行。guest 无图形会话、锁定、显示断开或输入通道不支持时显示具体状态，不伪装实时画面。重连后重新观察，禁止自动重放不确定输入。Docker 可作为环境实现选项，不新增必填容器层。

数据归属、分支与并发

Resources 保存可序列化的资源描述，真正的 Page/窗口/VM 句柄及租约仍由宿主管理。复用现有会话与分支投影，分组键必须来自稳定的分支身份或可验证的分叉谱系，不能使用不断变化的当前消息 HEAD，也不能把一次执行当成一个分支。分支改名、继续对话和重试只更新展示或关联；分叉不会复制真实网页状态。

  • 资源描述包含资源 ID、类型、脱敏目标描述、真实所有者、生命周期状态、连接代次和预览能力；分支关联另外保存来源调用、所属分支、子 Agent 和共享方式。同 URL 的不同 Page 不合并；同一 Page 的 UI 与使用记录合并为一个真实资源。
  • 子 Agent 资源在父会话原始分支下展示，并标明实际子 Agent 所有者；子 Agent 转向新任务或父分支改名不能改变历史归属。原会话/执行授权仍逐条检查，不能因为显示在同组而越权。
  • 从共同祖先继承的资源显示“引用自…”；浏览器默认新建独立 Page 用于分支写入，不能声称外部网站或登录状态因此隔离。原生窗口和 VM 不能自动克隆；需要显式转移写租约或提供独立目标。
  • 选择预览不是获取控制权限。同一个目标在各分支行中可作为共享引用出现，标明当前控制方；写入租约按实际冲突域互斥，如 Page、共享输入焦点的应用进程、VM 或宿主桌面。按窗口分组不证明应用能并发输入。
  • 预览事件带会话、分支、资源 ID、连接代次和单调序号；切分支、重连或撤销后丢弃过期事件。元数据可恢复，进程内句柄不可复用。旧记录无法归属分支时放入“待归属”，不猜测迁移。

预览、接管与断线

图像镜像只读，实际 tab 或原应用保持正常可用。人工入口与让出规则见下文。显式等待停止确认和用户直接访问是不同路径，不能把 Agent 的操作权限变成阻挡网页的遮罩。

后台空闲目标保留连接但停止高频截图；仅当前预览订阅图像，不周期扫描所有宿主应用。运行中显示帧的新鲜度与操作进度；最后一张截图显示“连接中断 / 最后画面”，未连接的资源允许查看元数据，但不提供远程输入。App 重启、网页崩溃与 VM 重启均需重新验证目标身份；持久记录不等于外部资源仍存活。内存不足时提示用户释放资源，不静默丢弃表单或停止 VM。

状态转换的确定规则

事件预览结果执行与目标
Agent 派发操作仅自动跟随且未隐藏时切到对应目标；手动查看或大视图保持当前目标。“正在操作”从经过校验的 adapter 派发开始，到回执、取消确认或失败结束。入队、持有租约、截图轮询都不单独显示该标记；超时或缺少事件显示“状态未知”。
点资源 / 预览 / 展开单击条目打开只读聊天镜像，不切换当前标签。“在会话中预览”使用同一 Page 身份，并在当前是网页时激活所属会话，使镜像可见。展开仅放大镜像。“打开页面”把真实人工入口显示为普通顶部标签并隐藏预览。预览选择不增加 Agent 写权限。打开后的真实页面中的用户输入触发 Agent 让出。
隐藏 / 恢复隐藏保存模式和目标，并保留 Page。没有单独的“显示预览”控件。单击资源行保持现有选择行为并恢复聊天预览。资源行上的“在会话中预览”恢复已隐藏的 PiP，目标仍是确切的现有 Page。列表继续更新。不最小化 OS 窗口，不切断 VM 虚拟显示，不结束执行。
跟随当前分支 / 恢复 Agent“取消固定预览”只改变选择模式，退出大视图。“恢复 Agent”才请求重新观察与自动化授权。查看或隐藏镜像不停止真实 tab 中的人工操作。等待停止确认超过 5 秒时，显示“暂停失败，请重试”，在仍连接时提供“重试暂停”，并保持禁止后续 Agent 派发；这是 UI 提示时限，不是已测停止保证。
目标冲突 / 子 Agent 结束显示真实控制方；不同目标可同时有多个“正在操作”条目，单个小窗仍只显示最新目标。第二个 Agent 写入者得到 busy，不隐式排队或抢占。需用户显式转移或分配独立目标；子执行结束释放自己的租约，父执行不能自动继承。
断线 / 目标失效 / 重启最后画面加失效标记，停用对应远程输入连接；未取得过图像显示“暂无画面”。身份和能力未知时停止写入，不显示“正在操作”。只自动尝试只读重连到可验证的同一实例；重建 Page、启动 VM、恢复写入须走显式动作和授权。

父分支的跟随集合包含父执行与在该分支创建的子执行，使用宿主派发顺序；子会话窗口只跟随子会话自身的分支。相同真实目标可在不同分支中显示引用行，资源数量按每组唯一目标计，Unavailable 的数量单列。“移除引用”只解除闲置关联；“关闭网页 / 停止 VM”作用于真实目标，必须列出全部受影响引用。任务完成保留原分组；App 重启保留分组与预览偏好，但不恢复远程人工输入连接或 Agent 写租约。标题和 URL 查询凭据不作为归属依据，不持久保存秘密查询参数。

原生输入的焦点或结果验证失败显示“输入失败”，撤销写入并保留证据，不能继续按后台模式尝试。无明确派发/结束事件的旧适配器显示“执行中 · 操作状态未验证”，不显示操作圆点，也不提供无确认的交互接管。宿主桌面按显示器标识绑定；屏幕布局变化令旧坐标失效。无论 App 是用户先打开还是 Agent 打开，断开关联均不退出 App；退出软件作为单独的用户明确动作。VM 的断开连接只释放传输连接，guest 与虚拟显示继续运行。

“当前分支”指当前会话聊天区域已检出的分支，资源选择不会更改它。“取消固定预览”只跟随该分支及其所属子 Agent；“恢复 Agent”是需要重新观察和授权的独立操作。

当前目标关闭或 VM 停止时，清除操作标记并显示该目标不可用或最后画面。手动查看一直保留此状态，直到用户另选资源；自动跟随也保留，直到当前分支有更新的获准操作选择另一个目标，不自行回退到旧资源。用资源行或“在会话中预览”恢复已隐藏预览，以及恢复分支偏好，遵守相同规则。

已有网页、操作提示与人类接管

PiP 只作为聊天预览。打开任意普通网页标签时隐藏该预览及其预留空间，让原生 Page 占满可用内容区。网页标签与其 PiP 不得同时显示。不得把 Page 截图叠在真实页面旁或之上，不得变暗、加遮罩，也不得用 CSS 藏起 iframe 却仍为原生几何预留空间。打开页面保持同一 Page 身份、资源和跟随偏好。返回会话后，除非用户已隐藏，否则按分支恢复预览。单击条目和跟随不抢占标签焦点。显式“在会话中预览”不揭示顶部标签；若当前网页占据中心，则激活所属会话使聊天预览可见。只有显式“打开页面”才把 Page 显示为顶部标签。真实网页在其自己的标签中保持可用、不变暗。完整网页工具栏、控制菜单和操作仍位于 Electron Page 之上。

同一原生 WebContentsView 不能同时占据两个矩形区域：页面标签当前时保留一个原生交互视图；仅当所属会话当前时，小窗才接收同一目标的截图/图像流。这里限制的是原生视图的同时挂载位置，不限制同一 Page 的 UI 引用数量；其他呈现位置使用镜像，定位现有 tab 时选择那个真实交互视图并隐藏预览。聊天中的小窗仍是会话上的悬浮预览。小窗图像区域严格只读，不转发缩放后的点击、键盘或滚动输入，也不为了放大缩略图而裁切或放大捕获画面。从未显示过的 Page 以 1920×1080 CSS 像素视口和用户正常页面缩放创建，使捕获有稳定的 1080p 布局；PiP 尺寸独立于该原生视口。可见 Page 回到后台时保留最后一次原生 bounds，不缩小到缩略图，也不重新套用创建默认值。不要把旧的 PiP 布局缩放路径用到缩略图尺寸上。“打开页面”定位到准确的现有 tab；没有可见 tab 时显式打开这个 Page 的视图，不另建 Page、不重复登录、不重载文档、不按 URL 猜测目标。原生窗口和 VM 同样区分真实控制入口与只读镜像。镜像隐藏不会中断已经打开的真实页面。仅查看或聚焦真实 tab 不触发暂停。

小窗可见时，持续订阅这个准确 Page 的画面，Agent 和人造成的变化都需要更新；不能为了截图搬走真实交互视图。每帧包含资源 ID、连接代次、序号与捕获时间，旧绑定的帧直接丢弃。适配器验收时确定有界刷新频率和过期阈值，显示最后画面的时间；捕获延迟或不可用时标为“最后画面”，不显示“实时”。静态截图不算实时镜像。隐藏小窗后取消对应捕获需求，Page 继续保留，不持续捕获所有资源。拖动聊天悬浮小窗时，在指针按下时缓存容器范围，并用动画帧上的 transform 预览位移。指针移动过程中不重新测量布局、不写入 React 或 store、不持久化矩形。指针抬起、取消和丢失捕获时，按当前容器范围再夹紧一次后写入最新位置。卸载、离开聊天宿主或切换资源时丢弃未完成的拖动，清除 transform 并释放指针捕获，不写入该矩形。拖动期间暂停截图与画面替换，并在指针抬起、取消或丢失捕获时恢复；已停止的循环不再恢复。暂停前已发出的捕获即使在恢复之后才完成也要丢弃；旧请求结束后立即开始一次新捕获，并保持单飞。暂停不得通过清空 isCurrent 永久停掉循环。

    哪些目标可以由人直接使用

    目标真实人工入口接管按钮与限制
    OpenProgram 已有网页 tab当前真实网页始终可看、滚动、点击和输入。只查看或切到该 tab 不自动暂停 Agent；真实输入、滚动、导航才触发让出。“打开页面”定位准确 tab 并隐藏聊天预览。“接管”显式等待停止确认。空闲和已关闭显示“可直接操作”，不提供暂停或继续按钮。用户也可直接操作网页，不出现控制遮罩。
    本机软件窗口人可以在原应用中操作，即使该应用尚不支持 Agent 后台输入。人工可用性和自动化能力分开显示。“在应用中接管”先请求 Agent 停写，再定位准确进程/窗口；用户明确点击后才允许将原应用置前。无法确认目标或停止状态时说明原因；不在窗口截图上伪造可输入界面。
    宿主桌面 / 显示器用户直接使用自己的桌面键鼠；小窗不是一个独立虚拟桌面。提供“暂停桌面操作”，输入来源是实际显示器及 OS。可检测的人类输入立即触发让出；无法检测或停止全局输入的适配器不能声明自动安全接管。
    有可写控制台的 VM在 OpenProgram 的 guest 控制台或已经连接的授权 VNC/RDP 控制台输入，不要求把宿主虚拟机程序放到前台。“打开 VM 控制台”复用同一个 VM/guest 显示。凭据、写权限、guest 图形会话和输入通道都有效才显示可操作；后台 VM 运行状态不因看预览而变化。
    外部浏览器、只读流或失效目标外部浏览器只有已验证 tab 绑定才能定位现有页面；同 URL 不能当成同一 tab。只读截图或断开的图像流不是人工输入入口。分别显示“在原浏览器打开”“仅查看”“需要重新连接”或“已关闭”。不得把只读资源统一标为可接管；重新创建目标是独立操作。

    让出控制的规则：人可以继续访问页面

    “Agent 使用中”表示宿主已授权的自动化写入状态；不是禁止用户访问页面的锁。用户在真实入口发出输入时，立即禁止冲突范围内的后续 Agent 派发、废弃待执行的旧帧动作，并请求暂停拥有写权限的执行。界面保持原亮度与可用性，在工具栏显示“正在暂停…”；不会复制或稍后重放用户点击。

    已经派发的操作可能无法立即撤回，尤其是原生输入和长时间浏览器调用。让出过程中可以有迟到结果，不能宣称“零并发”或已确认停止；未确定副作用单独记录，完成后重新观察，既不自动撤销用户修改，也不自动恢复 Agent。只有停止确认、输入状态释放和目标状态核对完成后，才显示“Agent 已暂停”。若失败或超时，工具栏明确显示“暂停失败，请重试”，在仍连接时提供“重试暂停”；用户仍可使用真实页面，Agent 保持禁止新派发。只有经过适配器实测，才能额外声明无重叠的自动接管。

    显式“接管”在停止确认后打开准确人工入口，避免把“已发送暂停请求”当成成功。等待期间按钮显示“正在暂停…”，已有真实 tab 仍可点击、输入和导航；禁用的是 Agent 后续派发，不是页面的人类输入。尚未打开的入口等待停止确认后再定位，用户仍可另行选择“打开页面”直接访问并隐藏聊天预览。空闲和已关闭目标显示“可直接操作”，不提供暂停或继续按钮。无法确认状态（连接已知断开时显示“连接已断开”）不得声称暂停失败，并保留禁用的“暂停 Agent，我来操作”。“暂停失败，请重试”在仍连接时提供可点的“重试暂停”，不得显示为已暂停。同一输入范围只保留一个停止请求：如果直接人工输入已触发让出，显式接管沿用该请求和确认，不重复停止。关闭接管入口的展示不会取消停止请求。正在暂停…、无法确认状态或暂停失败时禁用“让 Agent 继续”；“让 Agent 继续”仅在已暂停时可用；可重试核对停止状态，必要时重连到同一可验证实例，只有确认旧操作停止并核对状态后才进入已暂停。迟到确认也只转为已暂停，不自动恢复。由用户在真实页面主动操作触发的暂停没有需要确认的弹窗。返回自动化必须单独点击“让 Agent 继续”，重新观察并按当前权限获取新的执行许可；“跟随”只改变预览选择，不恢复输入，也不抢占标签焦点。

    预览、展开、隐藏、分支查看与真实输入权限分开。隐藏镜像不会撤销仍在可见真实 tab 中的人工操作，也不会恢复 Agent；关闭实际控制视图、失去连接或目标身份失效，会关闭该连接的自动化/远程输入权限并保持 Agent 暂停，不能声称 OpenProgram 能禁止用户使用本地 OS。当前选择其他分支只改变展示；已存在的接管请求继续按原资源 ID 跟踪，不转移到新选中的资源。

    真实页面中的指针按下（包括开始选择文本）、会操作页面的按键/输入、滚动和用户发起的导航触发让出；查看、单纯聚焦（包括 Tab/Shift+Tab 焦点导航和单独修饰键）、指针移动/悬停，以及操作只读小窗的查看控件不触发。悬停造成页面变化仍需使旧观察失效。浏览器适配器必须区分人类输入与 Agent 派发，接管识别不能只依赖页面内容脚本；不具备可靠识别的适配器仅提供显式暂停路径，不宣称支持自动让出。

    暂停范围由实际输入通道确定：浏览器按 Page 身份，现有 tab、第二个视图和镜像都关联同一个范围；原生窗口只有验证窗口独立输入后才按窗口，否则按实际共享的进程输入域或宿主键鼠输入域；全局桌面输入按宿主输入域；VM 按 guest 输入域，连接同一 guest 的不同控制台共享这个范围。关闭范围内所有 Agent 写入，不能只暂停发出请求的视图。真实 tab 在“正在暂停… / 暂停失败，请重试”期间仍能输入；只是不能报告“Agent 已暂停”，显式等待停止确认的路径也不能报告接管完成。

    边缘提示、工具栏与操作位置

    下面的描边、工具栏和动作标记只位于 OpenProgram 自有呈现区域：内嵌网页的宿主边缘/工具栏、OpenProgram guest 控制台，以及小窗预览层。原应用、宿主桌面或外部 VNC/RDP 客户端不属于这些区域；不改其菜单或绘制其外框，控制状态、“显示操作”和记录入口留在 OpenProgram 小窗或对应控制面板，动作位置叠在捕获预览上。打开原窗口只是定位人工入口，不意味着 OpenProgram 获得修改外部软件界面的权限。

    • Agent 活跃时，在目标视图外缘加约 1px 的低强度发光描边，不改变网页亮度、布局、滚动、焦点或点击区域，不采用持续闪烁。工具栏显示 Agent 名、分支和“使用中 / 正在暂停… / 已暂停 / 无法确认状态 / 连接已断开 / 暂停失败，请重试”；边缘只是辅助，不能只靠颜色判断控制状态。当前可见表面——真实页面标签或聊天 PiP，二者不同时出现——显示状态描边：使用中为蓝色，正在暂停…为低强度琥珀色，已暂停、无法确认状态或暂停失败使用普通边缘及明确文字，不继续显示活跃光效。
    • 在现有页面工具栏增加“显示操作”切换和“操作记录”入口，而不是在网页 DOM 内塞入按钮。“显示操作”默认开启，仅展示最近一次动作；打开记录后按顺序查看点击、输入、滚动、拖动、导航及验证结果，不改变 Files/Activity/Resources 导航。
    • 点击显示短暂圆环，拖动显示起止点和路径，滚动显示方向；输入只标识字段和动作类型，不显示密码或完整输入内容。键盘快捷键显示文字说明。标记归属于真实目标，而不是系统鼠标；绝不为了演示移动用户光标。
    • 只有可信宿主的派发/回执事件驱动标记，区分“尝试”“已派发”“已确认”“失败”“结果未知”。DOM ref 操作没有准确落点时显示元素范围或文字，不伪造像素坐标；原语回执不等于整个任务成功。
    • 用资源 ID、连接代次、观察帧和视口映射，把坐标转换到真实视图与缩放镜像。考虑内容区域、DPR、页面缩放、滚动和 iframe 偏移；导航、布局/窗口变化或过期帧使标记失效，只保留带旧帧标签的历史记录，不叠到当前画面。
    • 呈现层采用宿主自有、pointer-events:none 的显示层，实际输入事件仍交给原页面。Electron 原生视图上的显示层必须通过实机验证，不能假设普通 DOM 覆盖层必然可见；不能向外部网页注入脚本来模拟 Agent 的轨迹。真实视图的标记归 OpenProgram 原生宿主呈现层，小窗标记归预览呈现层；两者使用同一资源/帧映射和开关状态。关闭“显示操作”只隐藏两处动作标记，不影响状态描边、执行或操作记录。开始暂停时清除两处动作标记；正在暂停…、已暂停和暂停失败期间，迟到回执只进入带状态的记录，不画到当前画面。只有重新授权且帧有效的 Agent 动作才再次显示标记；减少动态效果时用静态短标记。

    后续复盘与学习：先保留可核对的记录

    复用已有操作回执，关联任务/分支/资源、前后观察、目标描述、动作参数、时间顺序、结果和用户修正。UI 的操作标记消费同一事件来源，不能另外捏造一套演示轨迹。记录首先用于调试和用户查看；用户确认后，可让 Agent 在后续任务读取选定的脱敏片段，分析错误定位或生成待验证的操作规则。

    “记录我接下来的示范”是单独的用户选项，明确开始、停止、范围、预览与删除。默认不录制用户的所有桌面动作，不保存秘密字段、密码、安全输入或带凭据 URL；屏幕图像只有经过允许和遮蔽检查才保留。无法可靠遮蔽时仅记录不含内容的动作元数据，放弃对应图像/示范片段。示范、自动化回执和失败轨迹分别标注，使用前要求用户确认选中的材料。

    任务内复盘、保存可复用步骤和模型训练是三个不同阶段。本设计不自动训练、上传数据或宣称“操作一次就学会”；生成的规则必须在独立测试目标验证，不能直接重放到用户的真实网页、软件或 VM。训练与数据导出需要后续单独讨论和授权。

    实施顺序

    1. 当前 Resources 交互为：分支分组、点击预览、显式“在会话中预览”、自动预览与固定预览（固定开关仅在小窗上，Resources 不提供 pin，也没有搜索框）、以及关闭语义。已隐藏的 PiP 由资源行“在会话中预览”图标恢复；单击行保持现有选择行为。没有单独的“显示预览”控件。隐藏保留 Page。
    2. 资源记录及分支投影保留持久描述、真实归属、子 Agent 引用与遗留数据迁移。
    3. 统一预览状态与 Resources 列表保留现有页面身份，并分离隐藏、展开和关闭。
    4. 真实网页标签与聊天预览互斥；人工输入让出、停止确认和显式恢复遵循当前接管规则。
    5. 原生窗口、宿主桌面与后台 VM 适配仍分别实施；每类只有真实目标验收通过才显示对应能力。
    6. 接入边缘提示、“显示操作”和回执记录；核验原生显示层不影响输入、坐标有效期、画面隐私。示范录制和后续复盘另行实施。

    验收用例

    • 一个分支打开五页：顶部标签不增长，五个资源均可在纵向 Resources 列表再次访问，预览随实际动作切换。对从未打开过的 Page 使用“在会话中预览”时保持该 Page 身份，不增加顶部标签，并进入手动预览。
    • 两个分支及其子 Agent 并行：按真实分支分组，切分支不改变外部任务，资源不会错误重绑定。
    • 手动查看 A 时 Agent 操作 B：A 保持聊天预览，B 仍显示“正在操作”；恢复跟随才切回 B。选择和跟随都不抢占标签焦点。
    • 隐藏、展开、折叠分组不会重载网页、停止 VM、授予控制或销毁目标。
    • 关闭使用中目标、撤销权限、迟到帧、重启与断线有明确状态，未确认停止不能报告已暂停，用户直接访问仍可用。
    • 打开网页标签时隐藏聊天预览及其预留空间，原生 Page 占满内容区。从该网页使用“在会话中预览”会回到所属会话并显示所请求 Page 的聊天预览。返回聊天后，除非已隐藏，否则恢复预览。页面不变暗，可直接操作，人工输入关闭后续 Agent 派发；迟到动作不会被误报为已停止，聚焦本身不暂停。
    • 当前可见的 Page 画面持续更新；捕获中断标注最后画面。操作标记不拦截输入，旧帧或视口变化后不显示错误坐标。
    • 同进程多窗口、用户同时操作和两个 VM 分别验证输入冲突边界；不以截图成功代替后台输入成功。

    会话工具活动详情

    computer_use_agent 调用在时间线中按目标和步骤显示：应用与动作（措辞与审批卡片一致）、Page 动作与 URL、虚拟机动作、在应用中运行的代码，或交给新 agent 的任务及其简报首行。早先 GUI 工具（gui_agent、computer_use、browser_use、vm_use）记录的调用仍可查看：选中后共享详情面板在原始参数与输出上方显示 GUI 操作记录卡片。卡片取代传输层的 Status 标签，因为函数调用完成不代表任务成功。

    • 结果：卡片标题与时间线行备注使用同一状态：运行中、动作已执行、成功、失败、需要接手、已取消、已中断、已暂停或结果不可用。没有明确状态的结果保持“结果不可用”。
    • 接手：突出显示已记录的阻碍和用户操作；与二者重复的摘要不再显示。任务全文只出现在原始参数中。
    • 步骤：每个已记录的能力调用一行（能力、目标应用或 URL、状态），按记录顺序排列。失败或停止的步骤附带最多两行的原因。步骤取自结果 history；运行中则从可见的能力子调用推导，不计入嵌套的规划调用。直接的能力调用自身就是标题，不显示步骤列表。
    • 归属：详情携带调用所属会话 id，不会替换其他会话中路径相同的详情。更新只刷新当前选中的调用。完整输出加载失败时显示错误，但不把调用标记为失败。

    不提供记录截图。截图路径位于可读附件目录之外的临时目录，可能已被删除；要显示截图，运行时需先把观察结果保留在会话目录中。
