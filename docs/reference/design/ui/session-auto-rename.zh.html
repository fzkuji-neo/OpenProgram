会话自动命名

会话菜单在 Rename 后直接显示 Auto rename。点击后使用已配置的标题模型，根据现有对话内容生成简短标题。手动 Rename 保持不变；后台标题调度不属于此次修改。

行为

侧栏原生菜单、侧栏 Web 菜单和对话菜单共用一个客户端操作。客户端显示进度，按会话合并执行期间的重复点击，并等待关联回复。生成期间，现有内容和旧标题仍然可见。失败时保留旧标题并显示可重试消息；传输超时则提示结果尚未确认，请用户重新加载页面检查最终标题，不自动重放操作。

现有 rename_session 命令未携带标题时，在工作线程中调用现有的无工具标题生成器，由后台任务管理，并立即释放 WebSocket 接收循环。任务保留至完成后再移除；请求方 socket 断开不会撤销已保存的标题。未验证原生 JSON Schema 支持的 provider 使用现有提示词回退，仍进行相同的本地 schema 验证且不使用工具。聊天历史提供文本；仅含函数调用的对话提供调用标题和结果。成功生成的名称先持久化，再广播 session_updated。已加载的对话与所有客户端显示相同标题。显式生成的名称按用户选定标题处理，后续后台命名不会覆盖它们。生成后再次检查对话是否已改名或删除，并丢弃过期结果。
