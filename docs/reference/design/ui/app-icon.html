macOS App Icon Specification

For desktop packaging and brand asset maintenance. Modern macOS uses layered Apple Icon Composer assets; OpenProgram provides a background definition and four independent brand depth layers. Source assets do not draw the outer system contour. Internal nodes retain lighting gradients that represent raised volume.

Raised-ring preview accepted · Installation awaiting Xcode license

Final decisions

1 · Background definition

The background color is defined by icon.json in automatic-gradient. Source assets contain no rounded corners.

+
2 · Four transparent brand layers

The orbit and three nodes use separate SVGs and enter four Icon Composer groups in back-to-front order.

→
3 · System output illustration

The Apple toolchain generates the outer rounded mask and edge effects. Internal node lighting belongs to the brand assets; Icon Composer adds inter-layer shadows only, without Specular halos.

Asset boundaries

Retain in source assetsA 1024 × 1024 canvas, blue-purple orbit with directional lighting and dark cross-section edges, three separate raised nodes with lighting gradients, transparent foreground, safe margins and clear contours.
Exclude from source assetsExternal squircle, rounded rectangle, outer frame, outer-contour highlights, pre-drawn drop shadows, blur, system-container materials and precomposited backgrounds.
Apple toolchain responsibilitiesFinal masking, inter-group depth, system highlights, refraction, opacity, shadows, platform shape, appearance adaptation and compatibility assets.
Do not replace component assetsWeb favicon, sidebar icons and loading animations retain their existing size-specific assets; do not export them from App-icon screenshots.

References and acceptance

The design follows Apple’s App icons HIG, Icon Composer and Xcode icon creation instructions. Packaging capability follows Electron Builder icon documentation.

Focused checks must confirm: all four modern SVGs use 1024 × 1024 transparent canvases without an outer squircle, frame or outer highlight; the three nodes use upper-left radial lighting; the ring has directional blue-purple lighting and dark cross-section gradients without white;icon.json declares four groups ordered orbit, large node, medium node, small node, all with Specular disabled and 42% neutral Shadow; package configuration uses .icon; the release runner provides Xcode 26.ictool must export Default, Dark and Mono successfully. Final visual acceptance checks Dock, Finder, About, and size and depth beside official icons.
