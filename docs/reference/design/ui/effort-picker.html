Effort picker

Design and reference

The composer Effort popup adopts the observed Claude desktop 2.31226.0 layout and timing: neutral stepped track, white handle, directional label transitions, and a sustained lavender square field at the highest option. Local published JavaScript and GLSL were inspected as reference; implementation is independently written. Claude has an Ultracode workflow mode; OpenProgram keeps provider effort IDs and adds no workflow mode.

Behavior

Options and Recommended come from the selected model. The highest of multiple supported options activates the field, including xhigh, max, or high. One or zero options never animate. Radix owns pointer and keyboard selection; state still flows through the existing composer settings. Fast and help remain independent. No changes to function calls, chat generation, providers, queues, or permissions.

Motion

Ordinary options use a neutral filled track with discrete ticks. Dragging enlarges the handle by 12%. Labels move vertically and resolve from blur in 200ms. The highest option uses rounded 3px squares on a 4px grid, randomly repeated propagation from the right, stepped brightness and independent slow variation. The field enters over 700ms and fades over 850ms when leaving the highest option; the canvas remains at full track width during exit. A compact Canvas2D implementation replaces the previous static SVG and global animation loop; no added dependencies or copied shader.

Lifecycle and compatibility

The component owns one animation callback. It cancels on close, unmount, hidden document, or reduced motion. Reduced motion retains a static highest-level tint. Theme colors come from CSS tokens; canvas failure leaves a usable slider. Device pixel ratio is capped at two. Named slider values, keyboard focus and the recommended tick remain accessible. Pointer cancellation clears drag feedback.

Acceptance

Exercise the actual ThinkingEffortPill: pointer and keyboard select unchanged effort IDs; xhigh activates sustained animation; leaving it fades to empty; reopen and model option changes work; Fast remains independent; reduced motion produces a stable frame; dark/light and narrow layouts remain legible.
