OVERVIEW

Scope and reading guide

The event layer is a process-wide EventBus. Producers construct a frozen Event and send it to the bus; consumers subscribe by type. gate events execute synchronously in the sender thread. The registry defines names, kinds and payloads; call sites establish production. Names, counts and source paths refer to the current checkout.

Status:Active call means the registry and emit/bridge/gate path are both identifiable;Registry only means currently declared only in the registry, not proof that runtime execution produces it.

System diagram

Multiple producers enter the bus through openprogram/events/. Consumers subscribe to typed events or read logs; WebUI passthrough uses the unregistered ws.frame envelope. Amber paths are synchronous gates; the current registered gate types are tool.before and turn.stop.

Cyan: typed events; purple: logging/observation; amber: synchronous gates.ws.frame and credential.* is unregistered and excluded from the 28 entries.

GUIDE · OBSERVE

Observation: subscribe to current events

Subscriptions are asynchronous observation interfaces. Handler return values do not affect the emitter.

from openprogram.events import get_event_bus

def on_file_changed(event):
    print(event.payload["path"], event.metadata.get("session"))

unsubscribe = get_event_bus().subscribe(
    on_file_changed, types={"file.changed"}
)
GUIDE · GATE

Synchronous gates: tool and turn-stop decisions

Registered gate types are tool.before and turn.stop. An empty return permits execution; a string denies it with a reason.tool.before also has a register_tool_gate compatibility entry.

from openprogram.events import get_event_bus

def guard(event):
    if event.payload.get("tool") == "bash":
        return "policy denied this tool call"
    return None

remove = get_event_bus().subscribe_gate("tool.before", guard)
Execution constraints:Gates run on the synchronous path; avoid model calls and slow I/O. Exceptions, soft timeouts and same-type reentry currently fail open.
DEBUG

Event log

The process-wide singleton bus writes typed dispatch to JSONL. With a session and existing directory, it writes to ~/.openprogram/sessions/<sid>/events.jsonl; otherwise to ~/.openprogram/logs/events.jsonl; rotate above 5 MB. Gate verdicts are stored in the same record’s gate field.

tail -f ~/.openprogram/logs/events.jsonl
Common registered typed events for a top-level turn include user.prompt_submitted, turn.start, model.response_started, tool.before, tool.after, model.response_completed and turn.end. Actual order depends on failure, cancellation, tool calls and stop-hook branches.
