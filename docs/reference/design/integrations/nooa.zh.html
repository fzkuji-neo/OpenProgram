设计范围

Agent 定义可复用模型配置。Context 定义父继承、命名内容、动态求值和历史可见性。

框架自动管理执行上下文。应用调用 agent() 或普通 Agent 方法，不需要手动构造 Context。

所有入口复用 Runtime、AgentSpec、工具策略、执行控制和 Session DAG。Agent 配置不默认拥有会话。

建议的用法

直接调用

from openprogram import agent

answer = agent("Analyze this paper",
               model="configured-model")

使用当前执行的会话；没有外层执行时创建独立的一次执行。

复用一个 Agent

from openprogram import Agent

bot = Agent(model="configured-model")
first = bot("Investigate this topic")
second = bot(first)

无需继承类。实例复用配置；历史是否连续由执行作用域决定。同一实例的独立顶层调用默认互不共享历史。

定义自己的类

class Researcher(Agent):
    model = "configured-model"

    def research(self, question):
        text = self.prepare(question)
        return self(text)

    def prepare(self, text):
        return text.strip()

result = Researcher().research("A topic")

方法正常编写，无逐方法装饰器；research 和 prepare 均可记录。self(...) 使用相同的 Agent 执行内核。

小写 agent() 提供便捷调用入口，大写 Agent 是可配置、可调用的类。二者进入同一内部执行函数；不创建进程级共享历史的默认 Bot。构造实例只解析配置，不发模型请求、不分配持久会话。首次执行时才解析会话和创建调用。

同步入口用于普通同步代码；异步代码使用 await bot.arun(...) 或 await agent_async(...)。已有事件循环内使用异步入口。

上下文的生命周期

触发条件规则
进入程序或顶层调用框架建立执行作用域并绑定当前 Context；存在外层会话时沿用其明确分支。
进入函数或方法派生当前作用域，保留父子关系与可见性规则；不复制完整历史。
每次模型请求之前解析 Context 的 DAG 来源、实例内容、动态内容和调用覆盖；筛选、去重、预算处理后生成模型输入。
模型返回将模型交互更新到当前执行状态；下一次构建可按规则使用。
函数返回、异常或取消恢复父作用域；已产生的模型交互按 expose / render_range 可见，不把全部子上下文无条件合并。
离开顶层执行解除任务局部绑定并关闭本次拥有的资源。复用 Agent 本身不延续历史；会话续接由宿主或显式会话选择决定。

调用关系决定上下文的继承与可见性；predecessor 决定会话顺序。Context 是运行时的构建对象，不要求复制或持久化每个时刻的完整内容。会话持久化与 Trace 导出沿用现有机制，不能决定 Agent 的上下文所有权。

Agent 调用、已注册的公开 Program 入口，以及所有者授权外部源码中的普通顶层函数负责建立执行。框架内部函数沿用活动 writer 与调用；没有公开入口或调用者负责执行时，内部函数正常执行，不创建独立 Session。在活动调用内仍完整记录 DAG 父子关系。结构调用保留在原始 DAG 视图中，但不新增聊天消息、会话分支末端，也不推进 HEAD。实际模型与工具交互保持原有会话行为。

行为测试的宿主在应用 OS 沙箱前初始化标准 SessionStore。测试进程通过 Context 绑定已有 SessionNodeWriter，Agent 调用复用它。候选测试不能创建子进程、修改源码快照、访问宿主秘密或使用网络。取消结束规范执行及其确切的 assistant 投影；结果未知的外部操作记录仍可检查。

普通函数采集

def research(question):
    data = prepare(question)
    return analyze(data)

def prepare(question):
    return question.strip()

def analyze(data):
    return agent(data)

受管 Program 加载器采集显式授权包目录内的源码函数，包括子模块和嵌套定义。函数签名、返回值、异常和 import 行为保持正常 Python 语义。

Agent 子类采集普通实例方法、静态方法与类方法，包括单下划线开头的方法。双下划线特殊方法与生成器不采集。记录私有帮助方法不会自动注册工具。

方法配置函数与受管 Agent 方法使用同一作用域处理，不重复采集。入口登记与工具暴露保持显式。

任意宿主文件、依赖包、lambda、动态生成代码与不可用源码不自动采集。其 agent() 调用仍可执行，但完整普通函数关系需要受管 Program 包或 Agent 子类。

统一 Context 模型

Context 具有父作用域、命名内容、动态提供函数和历史可见性规则。每次模型请求都使用同一模型。

组成行为
父作用域子上下文继承当前执行上下文。作用域退出时恢复父绑定。
内容命名值提供指令和业务数据。子上下文可覆盖名称，不修改父上下文。
求值Python 提供函数收到当前 Context，在框架构建模型请求时运行。
可见性现有 Session DAG 按分支、调用作用域、expose 和 render_range 选择允许读取的交互。

实例绑定是命名内容的特例。调用派生 Context 时加入 Agent 配置中的内容。Agent 实例不默认拥有执行会话。

父 Context + Agent 配置 + 调用内容
    → 派生当前 Context
    → 求值命名内容并选择可见 DAG 交互
    → 应用现有预算与压缩
    → Runtime.exec 模型请求

历史选择与内容替换分别处理。文本相同不表示交互相同。框架在实际请求中记录选中的 DAG 身份。

Context 不增加第二个历史数据库或 provider 运行时。工具授权与历史可见性分别处理。

显式事件生命周期

Context(store=writer, head_id=None) 为重复调用绑定现有 SessionNodeWriter。Context 会话通过已有 Session DAG 续接模型交互。

head_id 选择已有分支末端。未指定末端时续接当前会话末端。调用者拥有显式提供的 store。

NOOA 式实例事件生命周期属于显式 Context 绑定。Agent 配置仍不默认拥有历史。

参数与权限

配置归属与优先级
model / effort / instructions / tools显式调用覆盖 → 实例配置 → 类默认 → 当前会话默认 → 产品默认。缺省与空列表等显式清空须区分。
expose / render_range默认沿用现有行为；method_options 或显式函数元数据提供可见性设置。
tool visibility / approval独立于 DAG 可见性；必须经过现有工具注册、权限检查和审批。更内层的配置不能扩大外层权限。
AgentSpec / session持久 Bot 配置复用 AgentSpec；执行作用域引用 Session DAG；实例可配置 Context 内容与来源。仅创建 Python 对象不自动创建侧栏 Bot 或调度任务。

构建上下文默认只需要模型交互与必要调用关系；普通函数的完整参数、返回值和局部变量不属于默认采集要求。显式传入的模型内容仍需有界序列化；self 使用身份或类型引用，不序列化整个对象或客户端。方法名必须包含模块及类限定名，避免两个类的同名方法冲突。普通 Python 副作用仍遵循宿主执行和沙箱规则；记录调用不等于对任意 Python 操作逐一审批。

并发与失败

当前 Context、调用身份和有效配置使用任务局部绑定，进入时保存、退出时恢复。继承时不复制完整历史，也不共享可被原地修改的分支配置。嵌套调用可重入；共享 Agent 配置不意味着共享执行上下文。若显式使用可变实例内容或共享会话，需要明确的同步与快照规则。

异常、超时、取消均恢复父作用域，保留已完成模型交互的状态。独立调用复用现有权限请求上下文；缺少审批时沿用非交互规则。恢复仍通过现有安全点和显式步骤完成，不恢复任意 Python 栈。

代码范围

Context 位于 openprogram/context/model.py，Agent 位于 agentic_programming/agent_class.py，共用调用作用域位于 agentic_programming/call_scope.py。

Runtime 历史选择保留在 agentic_programming/runtime/history.py。受管源码加载保留在 programs/_source_loader.py 和 _registry.py。

统一建模与实现契约

Context 是具有父作用域、命名内容、动态提供函数和历史可见性规则的类。所有请求使用相同的构建过程。DAG 只提供可见交互及调用关系，不作为另一个策略。实例绑定是该模型的特例：将命名内容绑定到实例，再在调用时加入当前作用域。

公共入口为 Agent、Context、agent 和 agent_async。Agent.__call__ 提供同步调用，Agent.arun 提供异步调用。Agent 子类普通方法，包括单下划线帮助方法，自动建立作用域。已登记 Program 的普通函数由限定源码加载器处理。业务代码不需要逐方法配置，也不需要手动启动 Trace。

Context.current() 返回当前绑定。Context.derive() 派生子上下文。Context 支持命名内容、动态提供函数以及可选历史过滤。bind() 发布当前任务上下文及显式 writer，拒绝与已有 writer 冲突，退出时恢复绑定。动态提供函数收到当前 Context，构建请求时求值。使用 Python callable，不执行字符串表达式。显式修改实例内容保留在实例上，框架生成的模型交互属于执行会话。

共享 CallScope 负责调用 ID、父子关系、函数说明、终态和 Context 生命周期。Agent 方法与受管源码入口复用它。新普通函数节点只需结构信息。显式 capture_io、expose 与 render_range 保留原记录行为。生成器暂不自动采集，不在函数创建时伪造已执行状态。

模型请求继续经过 Runtime.exec、现有 provider、工具权限、预算及压缩路径。无外层执行时创建本次拥有的执行环境，结束时释放。模型配置相同或 Agent 对象相同不意味着会话相同。异步分支各自派生上下文，并保留明确调用身份。

实现包含统一 Context、Runtime 构建、共享调用作用域、Agent 类与便捷入口、已登记源码采集、产品文档和已交付程序迁移。NOOA 的 Predict、CodeAct 与完整 API 兼容不属于上下文建模等价的要求。

按用户要求优先编码。只运行覆盖公共入口、分支隔离、迁移后的原有行为及权限的必要验证。验证在后台进行，独立编码继续。完成前检查结果，不用未结束的测试证明完成。英文接口说明与错误信息采用 ASD-STE100 的简短句和一致术语。

实现范围

实现复用 Session DAG、Runtime、AgentSpec、权限检查、预算和压缩。方法配置与新自动作用域使用共用的调用作用域。

自动源码采集仅作用于受管 Program 加载器选择的源码。普通宿主文件和依赖包不自动采集函数调用。

入口登记和工具暴露保持显式。记录私有帮助函数不会将其注册为模型工具。生成器创建不产生已完成函数记录。

公共 API 与实际迁移必须符合已实现的加载器和执行范围。独立代码审查和受影响检查决定下方实现状态。

移除装饰器 API

Agent 与 Context 承担完整函数执行约定。删除的公共装饰器没有兼容适配器。Agent method_options 保留输入元数据、Runtime 注入、登记与 schema、可用性、权限、可见性、重试、执行控制及显式步骤恢复。

受管源码声明 PROGRAM_ENTRIES 与 __agent_options__。内部模块引用 call_state.py，方法使用 _is_agent_method 标记。已有执行节点数据格式与会话历史保留。

第一方 workflow、生成程序、扫描器、分发器和文档使用普通 Agent 类，不引入替代装饰器。

GUI、research 与 wiki harness 的源码迁移保留 agentics 包路径。构建阶段使用 scripts/release/program-patches 内的源码补丁产生待安装包，stage-program-source.py 应用源码变更，product-runtime.json 校验 checksum。这属于源码构建步骤，不是运行时兼容适配器。

六个本机已发布 workflow 同样在隔离源码中迁移并本地集成。本机与打包变更不证明上游远端已经发布。

装饰器移除和源码迁移已实现，独立规格审查与质量审查均通过。针对性检查覆盖源码加载、schema、Runtime 注入、权限、取消、恢复及不同方法的身份。实际本地源码和已安装 App 的部署另行验收。
