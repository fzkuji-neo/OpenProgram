Program、Agent 方法与工具

Program 是持续维护的 Python 包，包含确定性帮助函数、模型请求与编排。这些职责不要求不同装饰器类型。

编写与上下文

Agent 子类使用普通方法。框架自动建立调用作用域并派生 Context。模型配置属于 Agent；父继承、命名内容、求值和历史可见性属于 Context。

统一 Agent 与 Context 契约定义公共类 API 与执行生命周期。本页只定义 Program 和工具范围，不重复该契约。

工具与入口登记

方法记录不会自动注册工具。Agent.method_options 可通过 tool=True 显式登记方法。已登记 Program 源码通过 PROGRAM_ENTRIES 列出公开入口。显式元数据保留公开名称与输入表单。

通过 function() 登记的确定性工具复用现有 registry。授权与调用记录、历史可见性分别处理。

Skill 与普通代码

Skill 提供指令，不自行创建可执行入口身份。Program 提供源码与已登记调用入口。普通帮助函数保留 Python 行为。

方法功能

Agent 保留为已有入口元数据、工具登记与显式持久步骤的适配器。新 Agent 方法与受管普通函数不需要它。
