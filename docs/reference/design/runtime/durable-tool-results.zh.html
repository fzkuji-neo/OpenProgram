当前设计

保留检查点元数据、引用数量、控制消息预算、内容哈希和执行所有权校验。完整的助手回复与工具结果保存为按内容寻址的独立 blob，不受待处理消息的 64 KiB 限制。blob 存储不以 1 MiB 为拒绝条件；该值仍是展示分页或生产者分块的目标大小。模型输入策略不因此改变。

实现状态

已实现并验证：大图片和文本的完整保存、新建 store 后恢复、完成记录引用复用、损坏检测。此前受影响层与契约检查为 1,422 项通过、1 项跳过。未在本次实现：模型侧统一预览与按需读取、图片局部查看；这些能力需先核实现状。原会话 reconciliation_required 状态没有自动恢复，原会话截图没有重新执行。

执行前暂停

在已完成操作与下一次模型请求或工具调用之间接受的暂停，必须在下一次实际执行前处理。已经登记但尚未开始的操作记为未执行，并保留在 Agent 恢复位置中。首次操作前暂停的任务从原始持久化输入恢复，不生成虚构模型回复。保存结果期间控制命令改变执行状态版本时，只在相同 attempt 约束下重试 checkpoint 发布，不重新执行外部操作。

Python 执行结果

execute_code 公共工具将 Python 非零退出和超时标记为错误，同时保留 stdout、stderr，以及已观察到的退出码或超时。成功执行保持成功。本地沙箱拒绝保留原有结构化元数据。使用现有 ToolReturn 结果协议，不新增重试、不改变后端选择、不重复执行子进程。验收通过已注册工具的 AgentTool.execute 执行真实成功、失败和超时的 Python 片段；后端超时适配保留部分输出。源码验证与已安装 App 的显示验收分开记录。

达到委派上限后读取已有 Agent 结果

协作链达到 agent.max_messages 时，job_output 仍可被发现和调用。读取已有 Job 结果不创建新执行、分支或投递，不消耗委派额度。已有会话及祖先所有权检查继续限制结果访问；消息耗尽时 agent 仍被隐藏，send_message 保留投递时的消息预算检查。验收在配置上限处解析公开可用工具目录，经 AgentTool.execute 读取本会话已完成 Job 的结果，并在等待前拒绝其他会话的 Job。不新增取消工具。独立审查和最终组合检查分别绑定实现证据。

辅助 Provider 调用结果

已注册的 image_analyze、image_generate 和 mixture_of_agents 工具保留各自执行分支已经确定的成功或失败状态。局部 outcome 函数使用现有 ToolReturn 并明确设置 is_error，公开 AgentTool.execute 接收该结构化结果。原有普通 execute 函数保持原参数签名和字符串返回值。Provider 或模型不可用、显式模型引用无效、图片 Provider 调用失败、图片保存失败、所有参考调用失败和汇总调用失败返回明确错误结果。模型成功回答以 Error: 开头时仍然是成功。部分参考调用失败保留既有成功汇总或单参考回答行为。Schema、注册名称、源模块、后端选择、结果路径、重试预算、usage 标签和取消语义保持不变；公共 normalizer 不根据文本推断错误。验收通过真实已注册 wrapper 执行受控官方 Provider 传输回复和自有 PNG 输入输出，并验证未知模型、后端不可用、调用后端前的沙箱拒绝及取消传播。受控回复验证本地执行行为；真实凭证与远程模型或图片能力单独验收。
