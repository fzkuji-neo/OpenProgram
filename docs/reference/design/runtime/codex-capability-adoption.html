Codex capability audit and independent additions

Add only independent missing capabilities. Existing or partially overlapping implementations stay unchanged. A different feature flag, tool name or implementation does not establish a missing function. This audit uses a pinned official source snapshot and does not claim parity with all current Codex products.

Coverage: 147 feature flags, 30 CLI subcommands and 38 tool-handler modules, all classified. Experimental, removed and internal entries are included; counts are not counts of independent product capabilities. Overlap classifications do not assert identical behavior.

Adoption contract

Retain a read-only permission-rule explanation/self-test CLI using the original matcher without changing enforcement. Retain optional macOS command-domain restrictions using an authenticated local proxy and Seatbelt; default networking stays unchanged, private destinations are rejected, and unsupported Linux/WSL domain mode refuses execution. Add optional idle-system-sleep prevention during agent execution, disabled by default and macOS only. An IOKit assertion belongs to each active execution and is released on completion, error or cancellation; display sleep and explicit user sleep are unaffected. Configuration is read at the next execution. Acquisition failure logs a warning without failing the task.

Earlier additions to context, patching, environment filtering, project instruction hierarchy and context-remaining tools are removed from this candidate, preserving existing implementations. Sleep prevention adds only a default-inactive resource lifecycle around dispatcher execution and does not replace execution algorithms.

Acceptance requirements

Final verification enters through public CLI rule explanations/assertions, sandbox command restrictions, configuration and the real dispatcher lifecycle. Cover disabled defaults, cleanup on failure, independent concurrent assertions and unsupported platforms, then affected tests, the full gate, documentation links and installed-App acceptance. No new passing results are claimed.
