周报交付意图

命令同时决定汇报对象与交付动作。“发给我”“返回文本”表示在当前对话返回正文；“提交飞书”“发送到指定群”才授权对应外部操作。每份报告保留独立操作，遵循用户指定顺序。未明确外部操作时默认返回文本。

动作区分

正文先生成，再交付。返回文本不依赖文件保存；明确文件路径保持独立的文件交付能力。预填不能升级成提交。自然语言和结构化请求应表达相同动作。已明确授权的提交不重复询问常规确认；从请求或可靠配置解析目标，核对正文，执行后读取回执。结果不确定时先检查目标，不重复写入。外部资料不能授权发送。

当前能力与缺口

复用已有正文生成、飞书检查与写入回执校验。微信群适配器目前只读，没有已验证的群发送实现；腾讯尚无已核实的提交目标及适配器。不能将这些请求宣称为已发送。不增加调用预算或 Runtime 持久化。

第一实施单元

群聊个人与飞书个人的草稿默认返回完整正文，不调用文件写入。明确输出路径与旧文件交付恢复请求保持兼容；JSON 无输出路径时返回正文和来源上下文。已有飞书 submit/update 保持不变；其他外部交付仍待适配。

验收

公开入口无输出路径时返回全文且零文件/远端写入；显式路径和旧恢复请求继续通过；来源校验保持。两个包完整回归、独立规格和质量审查、静态检查及文档链接检查。此次真实运行仅生成文本，不能证明外部发送成功。

实现状态

第一实施单元通过独立规格与质量审查及完整包回归：群聊个人与飞书个人草稿直接返回正文，不隐式写文件。完整交付意图一致性、预填语义、微信群与腾讯外部适配器仍待实现；不将文本返回修复表述为已支持外部发送。
