Codex 功能核对与独立补充

只补充没有的独立功能。已有或部分重叠的实现一律保持原样；功能名称、实验开关或实现方式不同不代表缺失。此表核对固定的官方源码快照，不声称与当前全部 Codex 产品等价。

覆盖 147 个功能开关、30 个 CLI 子命令、38 个工具处理模块；全部有分类。包含实验、废弃与内部入口；这些数量不等于独立产品功能数量。分类依据已有能力边界，并不表示行为逐项相同。

采用边界

保留权限规则只读解释/自检 CLI：调用原有匹配器，不改执行策略。保留 macOS 命令域名限制：可选认证本地代理与 Seatbelt；默认网络开关不变，拒绝私有目的地址，Linux/WSL 不支持此模式时明确拒绝。新增任务执行期间阻止空闲系统休眠：默认关闭，仅 macOS，使用 IOKit 原生断言；每次执行独立申请，正常结束、异常与取消后释放；不阻止显示器休眠或用户主动休眠。配置变更在下一次执行读取。申请失败记录警告，不中断任务。

上下文、补丁、环境过滤、项目指令层级及上下文剩余量工具的此前新增改动均已撤回，保留已有实现。新增防休眠只在 dispatcher 的执行范围内增加默认无效的资源生命周期，不修改已有执行算法。

验收要求

最终验证从公开 CLI 的规则解释/断言结果、沙箱命令域名限制、配置项和真实 dispatcher 生命周期进入。覆盖默认关闭、失败清理、并发独立性和不支持平台；最终运行受影响测试、完整 gate、文档链接检查与安装 App 验收。当前无新增通过声明。
