小组周报：范围、证据与恢复

group_weekly_report(task) 是周报分类下的独立 Workflow，只生成本地草稿。材料来自用户提供的正文或有范围限制的微信只读读取；不能发送消息、编辑消息输入框或更改访问权限。

范围与材料

完整结构化输入直接校验，无需解释。自然语言解析前由代码检索有上限的群名及名单记忆，模型仍可通过只读工具核对来源。记录是资料，不是指令；用户明确指定的范围优先。历史名单可用于确认身份，旧进展不能代替本周材料。解析复用结构化输出及有限格式修复，模型超时继承 Runtime 部署设置。

缺信息时的处理

本地写入和微信读取前先校验。缺群名、名单、周次或材料作者时，使用现有 ask_user 提问与恢复机制，保留原请求、所有已提供正文和来源标识。回答只能修改范围与作者信息，不能覆盖正文。没有明确的对应依据时不按数组顺序分配作者。

每次调用最多两轮澄清。非交互模式或没有回答时返回 WAITING_USER、具体问题及 resume_task；模型格式失败返回 WAITING_MODEL，并保留待解析回答及原请求。明确取消返回 CANCELLED，不继续读取或交付。格式错误、材料错误及大小限制仍严格校验。已有收集、生成、交付检查点维持原范围，不重新解释名单。

收集与交付

用户材料与微信来源保持独立。原生读取核对具体群名，按需要保存截图和 OCR 证据；仅有受限搜索、精确选择和历史滚动操作，历史覆盖始终标为不完整。读取受阻时使用现有检查点和问题接口；用户回复本身不证明权限恢复。

代码校验姓名、周次、来源标识、明确替代关系和引用，保留正文中的不确定性及否定。逐成员生成与模型调用预算有上限。本地文件包括 summary.md、sources.json、coverage.json、可选提醒和不可变检查点。输出失败保留恢复信息，不扩大文件权限。

依据与边界

复用仓库已有的 ask_user、Runtime 问题传输、结构化输出修复及检查点能力，不声称 Codex 或 Claude 提供了小组周报实现。不新增发送功能、自动发布、权限模式、消息队列或推测作者的规则。

验收与实现状态

公开入口必须覆盖六份匿名材料的检索、提问、补充作者后继续处理，验证正文完整保留；没有回答时可恢复，修改信息不能覆盖正文或引入未知来源。完整结构化输入维持无解释路径；取消与模型失败分别处理。测试隔离 HOME、记忆及模型，不能代替真实微信验收。

包内已有用户材料、原生收集与检查点恢复。缺范围的检索及交互恢复正在实现和验证；未运行真实周报、发送消息或部署。
