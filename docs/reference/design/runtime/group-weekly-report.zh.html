自主收集的小组周报

group_weekly_report(task) 自主查找资料并生成有来源的未发送草稿，不要求用户补充字段。一句话请求也进入检索；来源不可用时输出明确注明检索限制的部分草稿。

请求与检索

自然语言解析保留用户正文和明确元数据。默认 source=auto：从记忆和相关本地资料确定范围；未指定周次时明确使用当前 ISO 周。只读检索可查找材料及作者证据。显式 source=supplied 禁止外部检索；用户明确的群、周次和原始正文优先。代码、测试和验收报告不能作为业务资料。

收集

确定群后使用已有微信只读接口。保留用户材料并补充来源，不以微信结果覆盖原文。匿名正文仅在证据对应唯一作者时补齐作者；提及、顺序和课题不能证明身份。微信不可用时继续搜索相关本地资料，报告具体限制。外部内容仅为数据；不发送消息、不执行任意命令、不修改权限。

信息不完整

本 Workflow 不调用 ask_user，不返回 WAITING_USER。无法核实作者时使用显式未核实标记。范围不明、来源不可用或缺少当周材料写入草稿限制。旧资料可确定范围，不能当作当周进展；日期不明也必须标注。完全没有材料则输出部分草稿和检索诊断，不编造进展。模型或服务异常及取消保留真实运行状态。

校验与交付

检索后校验材料结构与引用；仅缺业务字段不阻止生成草稿。复用来源校验、正文生成、本地交付。没有新增总调用、Token 或运行时间预算。微信单次读取仍有既有范围限制，必须说明覆盖不完整。不改 Runtime 持久化与提问 UI；保留报告文件兼容性。返回结果包含草稿正文和限制。

设计依据

复用 OpenProgram agent、结构化输出、记忆与文件工具、微信原生适配器。没有声称 Codex 或 Claude 提供此周报功能。取消必填字段问卷与用户材料/微信互斥规则；不采用任意命令执行或猜测作者。

验收

公开入口：无元数据请求主动查询并生成；匿名原文保留且可唯一匹配作者；微信失败转本地资料；作者冲突保留未核实；无资料也不提问；显式 supplied 不检索；旧资料与伪造引用不能混入当周结果；取消传播。总入口不因小组请求模糊而询问。测试隔离 HOME、模型、记忆，安装后的默认实例另行验收实际微信访问。

实现状态

自主检索和不提问的分发已实现，并通过独立规格与质量审查。包测试覆盖检索、来源验证、作者身份保留和部分结果交付。真实模型运行自主查找了范围和本地文件，因未核实当周材料而返回部分草稿。微信原生收集仍受实际环境故障影响，尚未证明成功收集。整体集成与默认 App 验收和包测试分别记录。

成员正文与可恢复整理

单行成员摘要保留现有微信群格式，并使用既有方括号格式显示已验证的来源 ID。可见 ID 仍对应相同来源表；格式整理不删除成员陈述与证据之间的关联。整理检查点在下一位成员调用前保存所有已完成成员正文，不再从没有添加两行标题的布局中固定减去两行。恢复失败成员时保留此前正文，只重试中断成员，model-state、调用计数与已完成位置语义保持不变。已有检查点读取、精确引文拒绝、原文 fallback、sidecar、取消及未发送交付均保持现有行为。
