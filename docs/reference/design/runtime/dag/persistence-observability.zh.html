由 Agent 分别管理执行 DAG

聊天记录自己的消息、模型请求及直接派发的工具。普通 Python 辅助函数不追加结构节点。调用另一个 Agent 时建立独立 DAG；父侧只保留调用、结果和子会话引用。

所有权

运行配置、权限限制与取消仍按原规则继承。图写入器、调用 ID、强制节点 ID、predecessor 和上下文历史位置属于子 Agent。显式命名 Context 内容仍可使用，父图历史不自动导入。返回、异常或取消后恢复父侧绑定。同一 Agent 的辅助方法沿用所有者，不产生辅助节点。正式工具派发保留记录，内部普通函数调用不因此成为工具。

实施计划

  1. 通过公共入口复现受管递归函数和聊天内不同 Agent 调用的边界错误。
  2. 将轻量辅助函数执行与操作记录分开，使用现有存储建立 Agent 子会话作用域。
  3. 验证同步、异步、嵌套、权限、取消、Runtime 注入和父侧恢复，修改原先要求辅助函数入图的测试。
  4. 完成独立规格审查、质量审查及完整验证后，本地集成并刷新默认安装 App。

验收

辅助递归零新增节点。父图没有子 Agent 的内部记录。子图不含指向父图的 caller ID。子记录返回后仍可读取。异常和取消恢复绑定。测试不调用真实 provider 或外部操作。既有历史不改写。

范围

本次实现 Agent 的图所有权边界。工具超时传播与浏览器期限控制仍是另外待修复的问题，不宣称本次已解决。不增加数据库、公共装饰器或另一套本地运行实例。
