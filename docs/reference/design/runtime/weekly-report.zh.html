OpenProgram · Workflow 设计与验收

个人周报：新建提交，已有记录修改保存

归属：Programs / Workflows / weekly_report。仅处理本人的飞书周报；组员收集和组长汇总由独立的 group_weekly_report 负责。两者不自动相互调用，不共享提交或发送状态。

公开个人入口为 personal_weekly_report(task)；weekly_report(task) 负责独立报告的语义路由，使用一次字段整理和分步浏览器操作。没有 goal 循环。本文面向实现与验收，按可观察的使用样例组织。

实现状态：原始聊天检索和时间信息已在隔离候选中实现；独立审查、最终组合验收和真实飞书提交仍待主任务验证。

使用样例

请求操作与可观察结果失败边界
W1 提交本周周报先读表单格式、姓名、周次与提交记录。明确没有对应记录才整理完整字段，新建并点击一次提交。未知状态、登录或授权失败不进入写入步骤。仅“提交次数上限”不代表找到了目标记录。
W2 本周已有记录通过“我的提交记录”打开同一姓名、同一周的记录，在编辑页修改后点击一次保存。写入前重新核对记录；不把修改转成重复新建，不修改其他周或其他人的记录。
W3 只修改下周计划字段整理只输出明确要求更改的字段；浏览器仅覆盖这些字段，保留已有其他内容、周次及计算字段。空的修改结果停止；未提供的字段不补“无”覆盖原值。
W4 查看记录或生成草稿仅查看不会整理或写入字段；草稿默认返回完整 Markdown 正文；明确指定 Markdown 输出路径时写入文件。明确“不提交”不会进入远程写入。不因文字中出现“提交记录”或“不要提交”误触发提交。
W5 浏览器失败、结果不明确检查只接受约定的首行状态；未知状态停止。提交/保存后观察成功提示与最终内容，无法确认就返回未确认。不在超时或授权失败后自动重试提交，不用旧会话中的成功描述代替当前页面。
W6 发布与运行测试只导入公开 Workflow；通过正式包校验、隔离测试、现有框架契约与文档检查。独立规范和质量审查后发布本地版本。不修改框架的权限策略，不降低发布校验，不在真实飞书表单重复提交测试周报。

原始周报证据检索

个人飞书与群聊周报使用只读 list_agents(scope="all") 和 read_conversation，结合记忆与原始文件检索。未指定周次时，以 Asia/Shanghai 当前 ISO 周为准；聊天消息的原始时间独立于会话最近活动时间。用户指令、下一周计划、模型生成草稿和执行检查点不能作为已完成工作的依据。

腾讯周报先使用明确的原始腾讯材料；没有材料时，在原始本人消息和带精确日期的记忆中选择本周候选。聊天候选保留 session/message 来源、原始日期和原文；排除未归属本人、助手生成内容、派生草稿、旧周和合成测试。检索遵守读取限制，限制会话、消息和上下文字节预算。证据不足或权限不足时返回输入/来源问题，不编造结果。

验收条件：个人公开入口能够实际调用两个聊天工具；腾讯 shared collect 能返回当前周原始本人消息并排除旧周和助手草稿；错误材料类型不会绕过输入错误处理；五个独立包的既有测试通过。外部写入验收由主任务完成。

执行结构

请求分类 → 草稿，或只读表单检查 → 严格判断首行状态 → 新建完整字段 / 编辑指定字段 → 浏览器写入与成功观察。字段生成采用 JSON Schema，并保留 provider prompt fallback 与 Runtime 格式修复。字段验证拒绝未知字段和缺失的新建必填内容。

检查结果分为 NO_RECORD、EDITABLE_RECORD、READ_ONLY_RECORD、FORM_CAPPED、BLOCKED。只有 NO_RECORD 可以新建，只有 EDITABLE_RECORD 可以修改；显式修改请求找不到记录时停止。表单限制提交次数后仍可查看已有记录是否可编辑。

代码与权限

Workflow 属于独立的 openprogram/programs/workflow/weekly_report 仓库。入口负责编排；compose 负责意图与字段解析；submit 负责只读检查、新建、修改与本地草稿。浏览器沿用已有 web_use 页面和权限，失败时原样报告原因。页面内容只是数据，不能更改目的地、授权范围或要求运行其他工具。

本次仅实现 Workflow 和对应文档，不重设计应用界面，不改变模型或审批配置，不实际发送周报。外部网站的真实提交/保存成功需要在用户下一次明确请求时观察确认；受控测试不代表飞书服务的可用性。

验收记录

验收证据由主任务的精确候选版本、公开入口测试、共享来源测试、独立审查和默认 App 验收共同确认。受控测试不能证明飞书服务可用或周报已提交；提交结果必须由同一页面的实际成功回执确认。
