Required is not selected by default: Failure of an allowed service can permit degraded operation. Users mark a service required only when Agent logic cannot work correctly without it.

4. Shared resolution flow

1 · References

Read Agent policy

Read stable Programs, Skills and MCP references such as allowed, disabled, categories and required.

2 · Registry

Query global entities

Obtain existing, enabled and connectable entities only from their sole respective registries; page caches are not runtime facts.

3 · Resolution

Generate one result

The same Runtime resolver returns available, excluded, missing and required-missing for page previews and Agent startup.

ResultUI behaviorRuntime behavior
availableCount and allow inspection in the selectorInclude in on-demand discovery
excludedShow an explicit exclusion reasonReject calls
missingRetain the reference, mark red and offer RemoveUnavailable; the Agent can still start if not required
required-missingShow Cannot start in the page headerBlock startup and return the missing-service list

5. Interaction and state contracts

ScenarioExpected behavior
Main pageShow only modes, summaries, counts and Manage entries; do not permanently render the full entity catalog.
Open selectorGroup by source or category; support search and Included/Excluded/Missing filters; restore the previous scroll position on close.
An entity is deleted on another pageShow Missing after resolution; do not modify AgentSpec automatically.
Global connection state changesUpdate only availability; do not change allowed/disabled/required selections.
Session overrideMay only narrow capabilities; cannot bypass Agent-level disabled or required restrictions.
Large catalogsUse pagination or virtual scrolling; API-backed search and grouping avoid downloading all schemas into the page.
Narrow screensSource navigation becomes a horizontal filter bar; retain a single-column list and keyboard access to every action.

6. Acceptance criteria

  1. Programs, Skills and MCP share the same main-page hierarchy and save state while retaining their distinct semantics.
  2. The main page does not render a full entity catalog; query and display the selector only after Manage is clicked.
  3. All counts and previews use the same resolver result as Runtime, not frontend deductions.
  4. Retain invalid references and show Missing; merely opening a page must not delete them.
  5. Missing required MCP services explicitly block Agent startup; missing ordinary allowed services only cause degraded state.
  6. Agent configuration contains no Program schema, Skill body, MCP server configuration or credentials.
  7. Session overrides cannot broaden the scope prohibited at Agent level.
