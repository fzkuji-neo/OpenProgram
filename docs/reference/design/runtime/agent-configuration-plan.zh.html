交付范围与已定方案

本计划实现关联配置契约。当前交付为文档及可在浏览器验证的编辑器原型，不迁移真实数据、不改变运行行为。首个功能版本包含保存/临时配置、原子保存、统一解析、可选记忆和页面。自动选择单独安排后续阶段，不作为手动逐调用选模型的前置条件。

  • AgentSpec 仍是唯一持久注册表，AgentConfig 是类型化配置值。复用 Runtime.exec、MemoryBackend、Context Engine、能力目录与资源管理。
  • 新保存或匿名配置默认关闭记忆；旧配置明确迁移并保留生效行为，不静默移动历史或记忆存储。
  • 模型在执行准入时选择，不在响应中途换模型，也不换模型重放已有副作用。
  • 只解析一个基础配置，不创建命名 Agent 继承树，不要求职责，不自动创建保存 Agent，不新建 worker 或编排引擎。

迁移、旧客户端与回退

  • 预检在配置写锁下读取所有 Agent、默认指针和原全局生效设置。dry-run 报告列 ID、格式版本、失效引用与语义差异，不含密钥或记忆正文。未知格式或损坏记录阻止该 profile 迁移，不能静默替换为 main。
  • 缺少版本的旧格式视为 1，规范化为格式 2、初始 revision 1。未知扩展数据在专门迁移备份中保留；尚未理解的执行字段禁止启用。明确保留旧记忆绑定与生效行为，不把旧 Agent 换成空 self 空间。旧全局继承作为命名兼容来源保留，直到用户选择具体模式。
  • 首写前按现有受限权限备份自有配置文件和 index。多文件修改使用日志与重启恢复；规范化校验通过才提交该 profile，中断可幂等继续。不修改外部目录、凭据、session、DAG 或已学习记忆内容。
  • 新 UI/API 写入要求 expected_revision。仍提供 updated_at 的旧客户端通过临时适配层：在同一写锁内比较时间戳，取得当前 revision，再完成一次原子写入。两者都缺少返回 428，页面保留草稿并提示重新加载，不能为兼容而接受无条件覆盖。
  • 未指定选择参数的 Python 调用保持原模型、历史、记忆和返回类型。新增参数仅限关键字。明确 agent_id/config 默认 clean，明确 inherit 仍受可见范围约束；重复别名冲突报校验错。现有持久委派 start_from 与 to 语义不变。
  • 回退代码必须使用能读格式 2 的版本，或停写后执行明确且已验证的降级。不支持的新字段阻止无损降级。恢复备份只适用于迁移后尚无修改，或已另行导出并处理后续修改的情况，不能覆盖用户新修改。旧二进制不得静默重写格式 2。
  • 只有第一方客户端更新并经过文档约定的弃用期，才移除适配层。先部署双格式读取 backend，再更新客户端、开启迁移，最后移除旧写入适配；不可先发布严格写入前置条件导致所有旧客户端失效。

可选选择策略：扩展接口与约束

P6 明确启用，在现有解析器之前执行。调用方提供已有选择策略引用，与 agent_id/config 互斥。候选是保存 Agent ID 或带 provider 的模型引用，不是自动生成的任意可执行配置。只选模型时保留调用方非模型字段；选择 Agent 时更换基础配置并使用常规历史规则。策略必须声明选择对象，避免选模型同时静默改变记忆和指令。

决策 契约
资格筛选 排序前排除不可用 provider/账户/模型，以及不满足模态、结构化输出/工具、上下文长度、授权或剩余额度的候选
排序 使用版本化、有序、确定性规则，读取明确任务标签、必需能力与调用方偏好；模型辅助排序另行启用
无匹配 / 不可用 返回无合格候选类型错误，或在推理开始前使用明确配置且仍合格的 fallback，不扩大权限
记录 保存策略版本、合格候选 ID、排除原因、选中 ID 与规则 ID，不保存原始用户内容，不编造成本或延迟
稳定性 重试/恢复固定选择，新调用可重新选择，不自动更换已开始工具循环的模型
评估 固定 fixture 覆盖选中正确性、无匹配、拒绝候选、未知价格、确定性重放；质量/成本/延迟主张必须有获准语料上的实测

一个 Agent 类型策略的所有结果都为保存 Agent ID：标签 classify 且要求结构化输出时，选择第一个合格且配置了指定小模型的保存 Agent；标签 code-edit 且要求工具时，选择指定的保存编程 Agent；其他情况选择明确的保存默认 Agent。另一个独立的模型类型策略只返回模型引用，并保留非模型字段。具体候选 ID 和阈值来自用户选择的可用目录，不内置产品排名。没有价格/延迟元数据表示未知，不代表免费或快速。

集成风险与明确限制

风险 处理要求
受限内容间接进入派生历史 沿上下文依赖与生成摘要传播写入限制；测试跨 Agent 转交，而非只检查原节点
插件不能强制空间隔离 明确显示不支持，阻止所请求的空间绑定，不声称提示词隔离
多文件与默认 index 并发 日志、恢复、幂等，由一个 manager 拥有修改权限
旧客户端覆盖新类型字段 双格式读取、条件写兼容与明确报错，不静默降级
配置快照含私人指令 沿用执行存储权限与保留策略，诊断只显示散列/引用，不显示 prompt 正文
页面字段先于运行支持 可用状态取决于 backend 验证，原型始终明确标记

开始 P0 不需要再等待产品决策。消费者精确文件位置与不同 backend 撤销支持是实施定位事项，上文已指定不满足时阻止执行的行为。不能满足的 backend 保持不支持，不能为了实现方便静默降低契约。
