策略语义与迁移

模式 请求集合 约束
inherit 采用基础策略 发现能力前解析
all 全局可用项目 仍应用拒绝和强制上限
selected 明确名称与类别过滤取交集；Programs 也可选择一个预设 显式 allowed=[] 表示空；Programs 不允许同时指定 preset 与明确名称
none 空集合 不能通过延迟按名称加载绕过

生效集合 = 请求集合 ∩ 全局可用 ∩ 调用方授权 ∩ 父委派上限 ∩ 环境限制 − 显式拒绝。失效引用仍保存但不可调用。必需 MCP 必须属于生效服务，矛盾模式包括通配拒绝都需校验。Skill 描述某个工具不等于授予使用权限。

目标格式为 Skills/MCP 同样加入明确 mode。旧 automatic 映射 all；disabled=["*"] 映射 none；allowed/categories 非空映射 selected；旧空 allowlist 仅迁移时映射 all。目标 selected=[] 绝不能进入旧空列表代表全部的处理。Skills 的 selected 模式中，allowed 省略且 categories 非空表示仅做类别过滤；两者非空时取交集。有类别项必须匹配，无类别项保留已有豁免，并在 UI 明示未分类。显式 allowed=[] 即使同时指定类别也表示无项目。名称和类别都缺少则不选择任何项目。旧 allowed 为空且类别生效时，迁移为省略 allowed，保留旧判断而非变成空显式白名单。规范化只在统一边界完成，不由 UI、搜索、执行器各自解释。

发现、调用与变化传播

  • 保存配置只保存意图。执行解析带版本的范围和目录/预设引用，不把全部 schema 清单加入首轮提示。
  • tool_search 只搜索生效范围，返回少量匹配 schema。按名称加载与嵌套 workflow/program 入口使用同一策略。
  • 真正调用时重查撤销、可用性和资源权限。即使排队或固定快照，已全局禁用能力也在下个边界禁止执行。
  • 可选 MCP 中断时禁用该服务并显示状态，必需服务中断阻止准入或启动。认证错误不自动换账户。
  • 失效名称在选择器内保持到明确移除，保存不抹除。预设更新影响新解析调用，运行中保留原意图，但仍受撤销限制。
  • 记忆读写工具还受执行记忆策略约束，能力 allowlist 无法覆盖记忆关闭或只读。

编辑器职责

Programs、Skills、MCP 分开。各自显示模式、继承来源、生效数量、失效数量和目录入口，只在打开时加载目录。类别/预设是选择方式，不是复制内容。MCP 增加必需标记与全局连接入口，凭据不进入草稿。列表、树与详情由 Programs 选择器文档定义，本页不重复目录。

验收：selected 空集合在搜索和调用均为空；被拒绝明确名称不能调用；必需服务缺失在副作用前阻止执行；失效引用重新加载后保留；切换分区保留统一草稿；记忆关闭时相关工具不能执行。现有策略基础已存在，目标规范模式与跨入口强制行为依实施计划验收。
