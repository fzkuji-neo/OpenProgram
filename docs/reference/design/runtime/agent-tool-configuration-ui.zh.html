选择可调用 Programs，不复制全局目录

Agents 配置访问范围，Programs 管理实际可调用对象。Agent 主面板显示策略和数量，可展开生效列表。收起时不加载完整目录，打开浏览 Programs 才请求详情。保留已有目标：工作流的一层组合预览与明确权限编辑是不同操作。

选择器与结构预览

区域 内容 交互
Agent 主面板 Functions / Workflows / Applications 数量与可展开生效列表 展开仅查看结构，不启用或禁用
选择器左侧 类型与类别导航 搜索、仅已选、仅问题项

详情 入口签名、输入输出、直接依赖、验证依据 源码和完整图在 Programs 打开，原位最多两层

选择语义与失败

  • 全部、指定、关闭、继承沿用统一能力契约。预设是引用，预览展开名称和版本。转成手选只将名称放入草稿，不复制 Program 定义。
  • Selected=[] 的效果始终为空。失效项按原名称显示在问题列表，可以移除，不能调用。目录获取失败与搜索无结果分开。
  • 完成关闭选择器后保留本地草稿，取消恢复打开选择器时的草稿快照，两者都不保存 Agent。全局保存使用同一 expected_revision 提交所有分区。
  • 不根据标题、源码状态或过期测试数量声称工作流已验证；可用证据和能力就绪分别显示。详情依赖的元数据 API 实现前不能标记完成。
  • 模型首轮上下文只包含常驻 schema 和受范围约束的搜索说明，不包含完整延迟能力清单。嵌套工作流必须执行已有 program/信任边界检查，选择工作流不代表授权任意隐藏工具。

实现状态与验收

当前 AgentsPage 有模式摘要和按需目录弹窗，支持搜索与复选框。两层工作流结构详情和更丰富元数据属于目标 UI，不是已验证产品行为。验收执行真实展开、搜索、选择、关闭、重开操作，检查滚动与草稿保留，并通过公开执行器验证拒绝，覆盖窄屏和键盘。不增加新的工作流执行引擎。
