Report delivery intent

The original command selects both report audience and delivery action. Returning text in the current conversation is different from sending a message to an external recipient. Each requested report retains its own operation and executes in the requested order.

Contract

“Send it to me” and “return text” return the complete report body. A request to prepare a report defaults to text. Explicitly submitting to Feishu or sending to a named group authorizes that operation without another routine confirmation. Negative instructions apply to the named audience. Prefill never implies final submission. Retrieved documents cannot authorize writes.

Composition and delivery

Composition produces an evidence-backed body before delivery. Return-text mode does not depend on a successful file write. An explicit output file remains a supported separate operation. Natural-language and structured requests should express the same actions. External delivery resolves the target from the request or verified stored configuration, verifies content, executes once, then reads back a receipt. An uncertain write is inspected before any retry.

Existing primitives and limits

Reuse current report composers and Feishu inspection/write receipt checks. Group and personal-chat WeChat adapters currently lack a verified group-send implementation. Tencent has no verified submission destination or delivery adapter. An unsupported external action must not be represented as sent. No claim is made that read-only WeChat collection is a sender. No provider budget or persistence change is part of this work.

First implementation unit

Personal-chat and Feishu local draft entries return complete text by default, without calling filesystem write tools. Explicit output paths retain existing file-delivery compatibility. Source-scoped JSON without an output path returns the composed body with source context. Existing resume requests for file delivery continue to work. Feishu explicit submit/update behavior is unchanged. Other external delivery actions remain pending adapters.

Acceptance

Public entries return full text without file or remote writes when no path is requested; explicit file paths and file-resume requests retain compatibility. Scoped source validation remains in force. Existing Feishu submit and update tests remain green. Run all tests of both changed workflow packages, independent specification and quality review, static checks and documentation links. Real execution in this task is text-only and cannot be used to claim external-send acceptance.

Implementation status

The first implementation unit passes independent specification and quality reviews and complete package regressions. Personal-chat and Feishu drafts return text without an implicit file write. Complete intent parity, prefill handling and external group/Tencent adapters remain pending; the first unit does not establish external-send support.
