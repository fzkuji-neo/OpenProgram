统一 Agent 执行

Agent 提供统一调用、会话轮次、异步取消、事件和恢复入口。Context 管理会话、历史选择及具名内容。ChatAgent 作为子类用于实际聊天。

职责

共享轮次运行时负责准入、模型和工具执行、压缩、流式输出、持久化及结束处理。旧 dispatcher 保留导入兼容。执行驱动继续负责持久化执行所有权、暂停、追加输入和断点恢复，不增加另一套任务管理。

边界

聊天各轮沿用会话图；普通函数不追加节点；子 Agent 使用独立图。Context 内容保持用户角色，不改变权限。恢复复用已保存上下文，不重复追加用户消息。工具超时产生工具错误，用户停止才取消整轮。

实施与验收

  1. 公开接口回归：会话、历史、内容、事件、隔离、取消。
  2. 完善 Agent 和 Context，迁移共享执行实现并保留导入兼容。
  3. 真实聊天及恢复入口使用 ChatAgent，保留现有执行驱动。
  4. 独立审查、全量测试、文档检查、安装验收。
