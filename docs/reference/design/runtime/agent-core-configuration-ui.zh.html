Web UI 布局与交互范围

沿用 Agents 列表与单个编辑器结构，八个配置分区共享一个草稿和一个保存入口。桌面保留左侧列表；窄屏改为顶部 Agent 选择器。试运行在宽屏显示右侧面板，窄屏使用带焦点约束的全屏面板。

图标直接使用仓库 components/animated-icons 的 pqoqubbw 动态组件及既有 start/stop 接口，悬停整个控件或键盘聚焦时触发；减少动画偏好下停用运动。Logo 使用项目现有文件，主题沿用 neutral light/dark token，不增加另一套图标风格。HTML 内嵌的是现有组件构建结果，不是新写的 SVG 替代图形。

试运行使用当前草稿与全新对话，记忆最多只读；选择“开始新对话”使用保存版本，并可在启动前覆盖本次模型、记忆和初始上下文。记忆覆盖只能收紧已有访问范围。两类操作都不修改已保存配置。原型明确显示模拟回复，不发送模型请求、读取真实历史或写入真实记忆。

状态选择器属于设计预览，可切换加载、空列表、错误、保存冲突和依赖不可用；不是产品设置。保存冲突展示两份指令并要求明确选择，不自动合并。生产实现接收服务端的模型能力、授权、生效范围及 readiness，不能照搬原型的示例计算。

交互验收覆盖八个分区、双语/深浅主题、桌面/窄屏、键盘分区导航、动态控件、草稿保留、冲突恢复与临时覆盖。原型通过不代表真实 API、权限或执行已实现。

编辑与继承交互

  • 有继承含义的字段提供“使用继承值 / 明确设置”，旁边显示实际值与来源。不可获取时显示未知，不制造默认值。
  • 模型选项来自已启用 provider/账户模型目录，保存完整 ID，不保存显示名。effort 跟随模型能力，原值不支持时保留并报错，不自动更换。Provider/MCP 登录仍在全局连接设置管理。
  • 保存 Agent 的继承字段来自系统默认，不来自打开设置页时碰巧使用的 Agent。调用预览可额外指定调用方/会话，必须显示预览范围。
  • 八个分区共享一份草稿，切换页签不保存、不清空、不单独提交。带修改离开时提供保存、放弃、取消；失败保留字段、选中项和滚动位置。
  • 草稿基于保存 revision；409 打开逐字段差异，指令正文不自动合并。更新基础版本后明确提交候选配置。必需依赖缺失影响就绪，不阻止保留草稿。

记忆与上下文控件

控件 可见结果 边界情况
关闭记忆 不检索、不写入；单独显示保留的原存储 不会移除对话里已经出现的事实
读写空间 选择自身/项目/共享引用并显示读写标记 改变共享范围需明确选择与授权检查
只读 显示读取标记，不把 writer 选项显示为生效 压缩与后续 writer 同样遵守执行来源资格
必需 backend 说明不可用时阻止执行还是降级 不能静默换到全局存储
上下文选择 继承 / 全新 / 明确指定资料 保留对话与保留记忆分别设置
指令文件 打开允许的文件，显示来源和散列/版本 缺失按必需性处理；打开页面不创建文件
频道重置 高级范围、空闲时间、每日时间和时区 仅影响之后路由，不合并或删除旧会话

生命周期与页面状态

状态/动作 要求的交互
新建 列表内名称输入，其他字段后填；失败保留名称，成功选中新配置
复制 预览配置与共享引用；不复制会话/记忆/计划；指令正文复制需明确选择
默认 仅一个权威默认值；影响之后按默认值创建的会话
删除 显示自有与引用资源；默认/忙碌状态拒绝；明确确认；不声称所有会话都在目录内
空/加载/网络错误 分别显示；API 读取失败不能显示空列表；重试保留草稿
依赖部分不可用 对应分区与就绪摘要显示不可用，仍可编辑其他内容
排队/运行中 显示配置版本提示并链接执行记录，不在中途静默切换
移动端/键盘 窄屏使用顶部 Agent 选择器，单列表单；方向键/Home/End 切换页签，可见焦点，原生控件
无障碍 正文基准 16px，辅助文字足够对比，字段标签和状态播报，不依赖悬停

组件归属与验收

复用 AgentsPage、ManagePageHeader、ManageRow、Tabs、连接/模型选择器与已有设置控件。只有行为和校验需要独立管理时拆分 panel，不新建页面/窗口框架。纯草稿规范化函数负责设置、重置和差异，服务端解析器仍是权威。权限和就绪错误使用类型化 API 响应，前端摘要不实现第二套策略引擎。

验收对应总设计 A01/A02/A07/A09/A10。通过构建页面操作八个分区、记忆模式、冲突恢复、失效引用、模型选择和键盘导航，不能仅用源码字符串检查证明行为。独立原型通过规格与质量审查、中英文桌面/窄屏浏览器流程，以及原有组件的动画检查；示例不发送模型请求。当前产品仍为六个分区，新增 API 接入与控件尚待实施。
