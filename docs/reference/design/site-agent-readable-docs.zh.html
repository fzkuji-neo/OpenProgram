Agent 文档

静态文档构建器在每个 Markdown 页面旁发布与源文件字节一致的 .html.md 文件，并在页面头部通过 text/markdown alternate 链接声明。文档首页使用 index.html.md，英文和中文各自对应原始源文件。

网站首页、文档页面和原始可视化页面通过 rel=describedby 指向站点根目录的 llms.txt。可视化页面保留 HTML 和现有可读性样式，不声明 Markdown 源文件。

兼容与边界

迁移适配当前 scripts/docs_site 和 website 目录，保留重定向、HTML 翻译、站点域名配置、GitHub 链接和导航。Markdown 内的链接保持源文件的相对路径。不增加运行时接口、认证或网络请求。

验收

检查 Markdown 副本字节一致、双语与首页链接正确、HTML 页面不被标为 Markdown、生成页面的 llms.txt 链接遵循站点域名配置，以及首页声明和指南中的目标均存在。
