Anthropic API authentication

OpenProgram uses the official Anthropic Messages API with API keys and API-account billing. All use must comply with applicable service terms and usage policies.

Architecture

API-key login stores credentials in the credential store. The resolver supplies an API key to the Anthropic SDK. Requests use API-key authentication. Model discovery and credential validation follow the same credential requirements. Compatible third-party APIs retain their own endpoints and credentials.

Boundaries

Unsupported credential types and providers are rejected before network access. Credentials remain masked in the UI. Login, model discovery, and inference must agree on which providers and credentials are supported.

References

Anthropic authentication and credential requirements. The official API uses API keys; external CLI account management remains external to this integration.

Acceptance

Provider, account, login, and model-list entry points enforce API-key authentication. Tests use synthetic credentials and no real provider requests. Verification status is maintained in the private implementation report.
