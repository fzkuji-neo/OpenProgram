Agent-readable docs

The static documentation builder publishes the original Markdown beside each rendered Markdown page. The HTML head advertises its source using an alternate link with type text/markdown. The documentation index uses index.html.md. English and Chinese sources remain separate and byte-identical to their repository sources.

The landing page, documentation shells and raw visualization pages advertise the site-root llms.txt guide with rel=describedby. The guide lists Markdown entry points and the existing HTML feature matrix. Visualization pages retain their HTML representation and readability assets; they do not advertise a Markdown source.

Compatibility and boundaries

This adapts the agent-readable-docs branch to scripts/docs_site and website. It preserves current URL redirects, translated HTML pages, configured site origin, existing GitHub links and site navigation. Markdown links remain source-relative. No runtime API, authentication or network fetch is added. Published sources are the same public documents already rendered by the site.

Acceptance

  • Every Markdown source has a byte-identical published sibling and a matching alternate link.
  • The docs index and both languages expose the correct source.
  • HTML-only pages have no Markdown alternate.
  • All generated shells and raw pages expose the configured llms.txt URL.
  • The landing discovery and guide targets exist in the build.
