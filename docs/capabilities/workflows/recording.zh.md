# 录制 Workflow

在 Mac 上把一件事做一遍，OpenProgram 记录下来，聊天 agent 就把这次录制做成 Workflow。录制适用于任何应用：网站、桌面应用、访达，或者一件事里用到的多个应用。

## 开始之前

- 录制在 macOS 上的 OpenProgram 桌面 App 里可用。浏览器里或其他系统上，**+** 菜单不提供这一项。
- OpenProgram 需要在 系统设置 → 隐私与安全性 里获得 **辅助功能** 和 **屏幕与系统录音** 权限。缺少某项时，开始对话框会指出是哪一项，并打开对应的设置面板。
- 语音讲解使用 **设置 → 语音** 里选择的语音识别服务和麦克风。没有语音识别服务时录制照常进行，只是没有讲解。

## 录制

1. 在输入框打开 **+** 菜单，选择 **录制 Workflow**。
2. 对话框列出会记录哪些内容。打开或关闭 **用麦克风讲解**，有多个麦克风时选一个，然后点 **开始录制**。
3. OpenProgram 窗口让开，一个小悬浮条停在所有窗口之上：已用时间、步数、麦克风开关、**丢弃** 和 **完成**。按平时的做法把事情做一遍。边做边说，尤其是下次会变的地方（"日期总是上周一"、"这个文件名每周都不一样"）。
4. 点 **完成**。OpenProgram 窗口回来，输入框里出现录制："录制的演示 · 12 步 · 48.3 秒 · 9 张图"。
5. 可以补一句话，比如这个 Workflow 什么时候运行，然后发送。

agent 读取步骤和截图，对决定 Workflow 输入的地方先提问，然后写包、运行 `openprogram workflows check`，最后总结步骤、输入和假设，供你纠正。对话里的录制显示为一张卡片，点开可以看到每一步和对应的截图。

录制最长十分钟，到时自动停止，等同于点了 **完成**；结束前 30 秒悬浮条会提示。**丢弃** 会停止并删除录制。发送前从输入框移除录制，磁盘上的录制仍然保留。

## 会记录什么

| 会记录 | 不会记录 |
|---|---|
| 点击，以及指针下的应用、窗口和控件 | 输入到密码框的文字（这一步只写明输入了密码） |
| 输入到文本框的文字，以及回车、Tab、Esc 和快捷键 | 在 OpenProgram 自身、密码管理器、钥匙串访问和系统凭据弹窗里的操作 |
| 滚动，以及切换到其他应用或窗口 | 音频：讲解转成文字后丢弃声音 |
| 点击、回车和切换窗口时的屏幕截图，不含 OpenProgram 自己的窗口 | |
| 你的讲解，以文字形式 | |

录制保存在本机的 `~/.openprogram/recordings/<id>/`：`session.json`、`events.jsonl`（每步一行）和 `images/`。发送时，步骤列表和最多 12 张截图会和其他消息内容一样发给你聊天使用的模型。录制文件夹可以随时删除；文件夹不在了，卡片会说明这台电脑上已经没有这个录制。

## 建议

- 一次录制只录一件事，从它平时的起点开始。
- 使用一次典型运行的真实输入。会变化的值，agent 会做成 Workflow 参数，分不清时会问你。
- 如果对话里的信息已经足够，不需要录制：直接让 agent 写 Workflow，它会先从之前的对话和记忆里补全，再问你缺的部分。

包的格式和 agent 运行的检查，见 [编写和检查 Workflow](authoring.zh.md)。
