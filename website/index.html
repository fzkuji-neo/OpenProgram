Self-programming AI agent framework

Build agents that program their own workflows.

OpenProgram agents are Python classes that can write new methods into their own code. Python owns the control flow and checks, and the model is called only where judgment is needed. Run them in one workspace with chat, files, a terminal, and a browser side by side.

How it works

Every call recorded. Every decision checked.

Python runs the program and the model makes the calls. Every call is recorded, every model decision is checked before it runs, and an agent can change its own code between turns.

support.py
from openprogram import Agent

class Support(Agent):
    def triage(self, ticket: str) -> str:
        """Classify the ticket, then draft a reply."""
        kind = self(ticket, choices=["bug", "question"])
        if kind == "bug":
            logs = search_logs(ticket)  # your own helper
            return self(f"Reply using:\n{logs}")
        return self("Draft a short reply.")

Branches and checks are plain Python. self(...) is a model call, and choices makes the model pick from a fixed menu.

    A graph, not a transcript

    User turns, model calls, and function calls are nodes in one graph. Each call reads a selection of earlier nodes, so a sub-agent works on its own branch and hands back only its result.

Quick start

Install, then run.

The installer brings its own Python. The first openprogram run walks you through connecting a model provider, either by importing a signed-in Claude Code, Codex, or Gemini CLI or by pasting an API key. openprogram web then opens the workspace at http://localhost:18100.

Prefer an app? The macOS Desktop App ships as a signed, notarized DMG on the releases page.
