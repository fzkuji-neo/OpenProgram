Grounding by description: wherever an action takes x,y, you may give describe instead, a short description of the target as it looks ("the blue Send button", "cell B2", "the gear icon top right"). The tool finds it on a fresh screenshot by visual detection (icon detector, OCR, remembered components, a model check) and acts at its centre. It is slower and costs model calls, so use element_index or ref when the target has one, and x,y when you can read the position yourself; use describe when neither works, or when working from a written brief.
